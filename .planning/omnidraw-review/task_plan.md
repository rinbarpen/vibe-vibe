# Omnidraw 科研图型样例 review

## 目标
按 Omnidraw 科研路由生成每类实际样例，保留 brief/source/prompt/图像/检查记录，形成可浏览索引供用户 review。内容均为合成示例，不代表研究结果。

## 图型覆盖（10）
1. 技术路线 / pipeline
2. 实验系统 / apparatus
3. 机制解释 / mechanism
4. 模型架构 / architecture
5. 多面板定性比较 / comparison
6. 图形摘要 / graphical abstract
7. 汇报总览 / roadmap
8. 封面主视觉 / cover art
9. 单面板数据统计图 / statistical chart
10. 多面板数据统计图 / multi-panel statistics

## 阶段
- [complete] 定义主题、交付结构、分工
- [complete] 生成 10 个样例及来源/提示词/代码
- [complete] 逐图审查：图型、科学语义、标签、灰色伪文字、数据边界
- [complete] 建立 review 索引并验证所有链接与文件

## 约束
- 不使用 Draw.io/Excalidraw。
- 主图不得生成小灰字、灰色占位横线、模糊段落或伪文字。
- 统计图仅使用显式合成数据并保留可执行代码。
- 若缺少实际 skill/runtime，记录使用的上游方法和未运行步骤，不冒充调用。
