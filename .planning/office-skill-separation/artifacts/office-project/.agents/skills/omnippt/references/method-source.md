# 方法来源与本地实现边界

方法启发来自 sandun（Sandun）发表于 **2026-03-19** 的 [《应该是目前最强的PPT Agent，附上完整思路分享》](https://linux.do/t/topic/1782304)，读取日期 2026-10-26。标题是原文名称，不代表本技能对产品或模型的排名结论。

借鉴的是高层设计思路：先了解听众和目标；以资料支撑论点；让单页想法可移动重排；先做清楚的内容策划，再处理视觉风格；按内容使用有主次、可灵活组合的卡片布局。这里不复制原文提示词、截图、画布参数或模型/服务推荐。

**下列是本仓库的原创工程选择，而不是原文承诺：**

- 六个按需本地子技能，输入足够时免额外研究，沿既有模板制作与局部编辑路线。
- Omnidraw / Omnisheet / 实际 PPTX 引擎分工；默认原生可编辑对象，SVG 仅为可选图源/规划素材，不把嵌入 SVG 等同所有元素原生可编辑。
- 图表、宏分别确认；源哈希/副本、机器合同、修订跟踪、真实文件检查、全页视觉与独立 QA。

[Microsoft SVG 编辑说明](https://support.microsoft.com/en-au/office/graphics-visuals/edit-svg-images-in-microsoft-365) 区分整体图形操作与转换为形状；具体可编辑对象及兼容性需在目标 PowerPoint 验证。本技能不据此建立整页 SVG 处理管线。
