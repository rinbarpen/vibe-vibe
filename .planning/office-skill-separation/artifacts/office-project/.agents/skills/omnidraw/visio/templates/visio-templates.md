# Visio Templates

## Draw.io → Visio Bridge Template
**→ [mermaid](../../mermaid/SKILL.md) → [visio](../SKILL.md)**
```
Step 1 (drawio): Draw [diagram type] for [purpose]. Standard shapes, orthogonal connectors. Export .drawio.
Step 2: Open .drawio in draw.io desktop → File → Export as → VSDX.
Step 3 (visio): Open VSDX. Apply [theme/template]. Add [stencils]. Page setup: [A4/Letter].
```

## Flowchart (Visio Direct)
```
In Visio: New → Basic Flowchart.
Start/End: Terminator shape. Process: Process shape. Decision: Decision shape.
Connectors: right-angle. Font: Segoe UI 12pt.
Page: Letter landscape. Export PDF for review.
```

## BPMN (Visio Direct)
```
In Visio: New → BPMN Diagram.
Pools and lanes for participants. Tasks: Abstract or Service.
Gateways: Exclusive (X), Parallel (+), Inclusive (O).
Events: Start (thin circle), Intermediate (double circle), End (thick circle).
Message flows (dashed) between pools. Sequence flows (solid) within pools.
```

## Org Chart
```
In Visio: New → Organization Chart.
Import from Excel or build manually.
Executive at top, direct reports below. Use horizontal for wide teams.
Add photos via shape data. Data-linked fields for dynamic org charts.
```

## Network Diagram
```
In Visio: New → Detailed Network Diagram.
Use standard network stencils: router, switch, firewall, server, workstation.
Subnets as containers. Label bandwidths on links. VLAN tags on switch ports.
```

## Cloud Architecture (Visio with official stencils)
```
Download official AWS/Azure/GCP stencils from vendor site.
In Visio: Shapes → My Shapes → Import Stencil.
Drag services into VPC container. Connect with arrows showing data flow.
Label with service names and instance types.
```
