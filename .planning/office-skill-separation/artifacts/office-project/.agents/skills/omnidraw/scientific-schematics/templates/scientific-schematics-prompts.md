# Scientific Schematics Prompt Templates

---

## Mechanism Diagram
```
Generate a scientific schematic of [biological/chemical/physical mechanism]:
Components: [list key elements]. Show [interaction/transformation pathway].
Steps: [step1] → [step2] → [step3] → [result].
Journal-quality: clean lines, consistent labeling, color-blind safe palette.
Export as vector graphic. Journal: [Nature/Science/Cell/PNAS/...].
```

## Experimental Setup
```
Generate a schematic of experimental setup:
Apparatus: [list equipment]. Samples: [description]. Measurement: [method].
Show [sample preparation] → [measurement] → [data collection] flow.
Include scale bars where relevant. Label key components.
Clean academic style, [journal]-compatible formatting.
```

## Research Proposal Figure
```
Generate an NSFC-style proposal figure:
Research plan overview: [Phase 1] → [Phase 2] → [Phase 3].
Each phase: research content, key methods, expected outcomes.
Connections between phases showing logical progression.
Academic style, clean layout, blue-gray palette.
Chinese/English bilingual labels as appropriate.
```

## Pathway / Signaling
```
Generate a signaling pathway schematic:
Membrane receptor → [downstream effectors] → [transcription factors] → [gene targets].
Show activation (→), inhibition (⊣), phosphorylation (P).
Cellular compartment labels (membrane, cytoplasm, nucleus).
Clean vector style, consistent iconography.
```

## Materials / Device
```
Generate a materials/device schematic:
Device structure: [layer1] / [layer2] / [layer3] / [substrate].
Show dimensions: thickness, width (labels).
Material composition labels for each layer.
Cross-sectional view or 3D exploded view.
Publication-ready, consistent labeling.
```

## Comparison / Model
```
Generate a comparative schematic:
[Model A] vs [Model B]. Side-by-side comparison.
Highlight differences: [key difference 1], [key difference 2].
Unified color scheme: blue for A, orange for B.
Annotation callouts for novel contributions.
```
