# Canvas Design Prompt Templates

---

## Poster
```
Design a poster for [event/topic]:
Title: "[title]". Subtitle: "[subtitle]".
Visual style: [minimalist/bold/editorial/retro].
Key visual: [describe central image/graphic].
Typography: [serif/sans-serif] for headlines, [complementary] for body.
Color palette: [primary, secondary, accent]. Include space for [date/time/location/logo].
Print-ready, [A3/A2/A1] size, 300 DPI.
```

## Brand / Identity
```
Design a visual identity board for [brand]:
Logo concept: [description]. Color palette: [list 3-5 colors].
Typography pairings: [heading font] + [body font].
Key brand elements: [patterns, icons, graphic devices].
Mood: [professional/playful/luxury/technical]. Visual examples for each.
```

## Editorial Spread
```
Design an editorial layout for [magazine/article type]:
Title: "[headline]". Byline: "[author]".
Visual direction: [fashion/tech/literary/news].
Key image: [describe hero image]. Pull quote: "[quote]".
Grid: [3-column/4-column/asymmetric]. Typography-driven.
Include [N] supporting images/illustrations.
```

## Event / Conference
```
Design a conference visual for [conference name]:
Theme: "[theme]". Visual direction: [tech/creative/academic].
Key graphic: [abstract or thematic visual]. Logo placement: top-right.
Typography: bold headline, clean body. Colors: [palette].
Applications: banner (1920×1080), badge, program cover.
```
