# Excalidraw Prompt Templates

---

## Architecture Sketch
```
Create an Excalidraw whiteboard sketch of [system] architecture:
Hand-drawn rectangles for [services]. Curved arrows for data flow.
Sticky-note style annotations for constraints and notes.
Rough aesthetic (roughness=1). Dark mode if preferred.
Export as PNG.
```

## Wireframe
```
Create an Excalidraw wireframe for [screen/page]:
Layout: header (rectangle, top), sidebar (rectangle, left), main content (rectangle, center), footer (rectangle, bottom).
Rough rectangles with placeholder text ("[content description]").
Simple rectangle = image placeholder. Hand-drawn style. Grayscale.
```

## User Flow
```
Create an Excalidraw user flow:
Screen [1] → Screen [2] → {Decision: [condition]} → Screen [3a] / Screen [3b].
Hand-drawn phone frame rectangles. Arrows between frames.
Label each transition with trigger action. Include "Happy path" and "Edge case" annotations.
```

## Brainstorm / Whiteboard
```
Create an Excalidraw brainstorm diagram:
Central idea: "[topic]" (ellipse, center). Branches: [idea1], [idea2], [idea3].
Connections: curved arrows. Sticky-note comments: [note1], [note2].
Free-form layout. Color-coded branches. Export PNG.
```

## Quick Diagram (URL scheme)
```
Generate an Excalidraw diagram:
URL: https://excalidraw.com/#json=[URL-encoded JSON]
Elements: [describe rectangles, arrows, text elements with positions]
Hand-drawn aesthetic. Share the link for collaboration.
```
