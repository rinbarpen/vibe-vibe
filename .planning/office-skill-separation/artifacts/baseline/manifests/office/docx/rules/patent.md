# 中国专利格式规则

## 三种专利类型

| 类型 | 保护期 | 保护对象 | 必备文件 |
|------|--------|---------|---------|
| **发明专利** | 20年 | 产品、方法、工艺、用途 | 权利要求书 + 说明书 + 摘要 + 摘要附图（如有附图） |
| **实用新型** | 10年 | 产品的形状、构造或组合 | 权利要求书 + 说明书 + 附图(必需) + 摘要 + 摘要附图 |
| **外观设计** | 15年 | 产品的形状、图案、色彩组合 | 图片或照片 + 简要说明 |

## 通用格式要求

### 字体与字号
- 说明书正文：宋体(SimSun)，12pt
- 权利要求书：宋体(SimSun)，12pt
- 各级标题：黑体(SimHei)，与正文同字号
- 摘要：宋体(SimSun)，12pt
- 英文/数字：Times New Roman
- 行距：1.5倍行距
- 页边距：上下左右各2.5cm

### 页码
- 从权利要求书开始连续编号
- 页码位置：页面底端居中

## 三种专利特有规则

### 发明专利

**文件组成：**
1. **权利要求书** — 独立权利要求 + 从属权利要求
2. **说明书** — 技术领域 → 背景技术 → 发明内容 → 附图说明 → 具体实施方式
3. **说明书摘要** — 150-300字
4. **说明书附图**（可选，但强烈建议）
5. **摘要附图**（如有附图则必须指定一张）

**权利要求结构：**
- 独立权利要求：前序部分 + 特征部分
- 从属权利要求：引用部分 + 限定部分
- 格式："根据权利要求X所述的...，其特征在于..."
- 编号规则：1、2、3... 连续编号，从属权利要求紧跟其引用的权利要求

**说明书各部分字数：**
- 技术领域：50-150字
- 背景技术：300-800字
- 发明内容：500-2000字
- 附图说明：100-500字
- 具体实施方式：1000-5000字

### 实用新型专利

**与发明的核心区别：**
- ❌ 不允许：方法权利要求、用途权利要求
- ❌ 不允许：材料成分、化学组合物
- ✅ 必须：有附图（产品结构视图）
- ✅ 可以：形状、构造、形状与构造的结合

**说明书侧重点：**
- 背景技术：描述现有同类产品的结构缺陷
- 发明内容：重点说明产品结构改进，而非方法/工艺
- 具体实施方式：结合附图详细描述产品结构、连接关系、装配方式

**权利要求限制：**
- 仅限产品权利要求（装置、设备、系统）
- 不可出现方法步骤、工艺参数、用途特征
- 结构特征为主，功能特征为辅

### 外观设计专利

**无需：** 说明书和权利要求书

**只需：**
1. **图片或照片**（核心文件）
2. **简要说明**

**六面视图（必须）：**
| 视图 | 拍摄方向 |
|------|---------|
| 正视图 | 正面朝向 |
| 后视图 | 背面朝向 |
| 左视图 | 左侧面 |
| 右视图 | 右侧面 |
| 俯视图 | 顶部向下 |
| 仰视图 | 底部向上 |

**可选补充视图：**
- 立体图（强烈建议）
- 局部放大图
- 展开图（折叠类产品）
- 使用状态参考图

**图片质量要求：**
- 分辨率：300 DPI 以上
- 背景：白色或浅色单色，无阴影干扰
- 格式：JPG 或 PNG

**简要说明内容（禁止商业宣传）：**
- 产品名称
- 产品用途
- 设计要点（形状/图案/色彩的结合）
- 指定一幅最能表明设计要点的图片作为主视图
- 省略视图说明（如有省略）

## 审查质量门

| 检查项 | 说明 |
|--------|------|
| 权利要求支撑检查 | 说明书的每个技术特征必须在权利要求中有对应 |
| 引用一致性 | 权利要求引用编号必须存在，不循环引用 |
| 术语一致性 | 全文同一概念使用同一术语 |
| 附图一致性 | 附图标记在说明书和附图中一致 |
| 新颖性/创造性 | 独立权利要求包含全部必要技术特征 |
| 格式合规 | 字体/字号/行距/页边距符合CNIPA指南 |
