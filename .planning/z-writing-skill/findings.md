# 发现
- ai-vibe-writing 已是 Skill，有 18 份按需提示词：样本文风、局部写作、语法、句间逻辑、章节、审阅、回复、品鉴等。
- z-humanizer 普通文本路由已打包 unslop；学术分支声明的两个子 Skill 缺链接，而规范源在 skills/ 下存在。
- auto-research Writing Plan 是科研节点/证据/审批工具，不是通用写作引擎；保持唯一计划事实源。
- writing-agent 是面向公众号/观点长文的独立项目，包含桌面与宿主特定编排；不作为所有体裁的默认流程。
- 安装器跟随包内链接并排除 Git 元数据，现有 z-humanizer/unslop 已有对应回归；不改通用安装器。

## 结果与边界
- 普通文本使用 z-humanizer/unslop；学术路线读取实际专业引擎，但不以检测率、配额或随机化作写作目标。
- unslop 文风统计偏英文；中文文风由有位置、分体裁的样本与实际段落对照，不套英文测量分数。
- 独立包能运行工具，不代表已完成某篇文章的模型写作或语义风格验收。
