# Vibe 多项目登记与更新

## 目标
成功安装后自动登记项目；按名称列出/查看、导入/重命名/迁移/移除登记；按项目更新指定或全部已安装 manifest/skills，支持全项目预览，保持 setup 双端副本与哈希一致。

## 阶段
1. [complete] 核对安装记录、setup 事实源与事务边界。
2. [complete] 全局索引、CLI 自动登记和每项目单事务更新。
3. [complete] 隔离回归、真实多项目 CLI 与回退、文档和 workflow 一致性。

## 决定
- 项目内 installations/setup 是资源事实源，全局文件只索引名称、路径和来源。
- 默认更新本地源，不自动 fetch/pull；新依赖不自动安装。
- setup 项目保留本地修改并同步双端；旧项目沿用既有 update 语义。每项目一个事务，跨项目不承诺分布式原子性。
