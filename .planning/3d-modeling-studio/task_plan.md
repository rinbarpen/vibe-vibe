# 3D 建模 Skill 实施计划

## 目标
在 mine/ 创建可被 vibe 发现和安装的多软件 3D 建模 Skill，以可执行管线、适用的精细建模技术与可证实的质量验收支持业内优秀作品目标。

## 阶段
1. [complete] 需求界定、官方资料核验和仓库约定检查。
2. [complete] 编写入口、软件路由、资产类型配方和质量门禁。
3. [complete] 实现可重用审计、预览和交付验证脚本及模板。
4. [complete] 正反测试、Skill 验证、vibe 发现/安装测试、回滚验证。
5. [complete] 汇总覆盖范围、调用方式、证据和真实执行边界。

## 决策
- “二右优秀”按“业内优秀”理解；不把面数等同于质量。
- 默认创建仓库第一方 Skill，不变更任何已有 Skill 或用户全局配置。
- 商业软件按实际宿主/API可用性执行，不声称所有软件已实机验证。
- 计划和运行证据独立保存，不给 Skill 添加无用辅助文档。
