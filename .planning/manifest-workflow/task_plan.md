# Manifest 工作流图交付规范

## 目标
新建或修改 manifest 工作流时，配套交付对应 SVG、可编辑源、再生成与漂移检查命令；图中清晰区分 AI 自主执行、验证和人工决策，并具备返工与恢复路径。

## 范围
根 AGENTS、两份 README、独立作者规范、零依赖渲染工具与真实示例、专项测试。保留全部已有 Unity 与 CLI 改动；本轮不批量重写业务模板或更改安装行为。
