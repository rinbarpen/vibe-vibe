# 主动学习技能 (Active Learning)

## 概述

基于认知科学的教育心理学研究成果。被动重读是效率最低的学习方式，主动输出才是深度理解的关键。

## 核心准则

### 1. 主动回忆 (Active Recall)
- 闭卷回忆比重读高效 50%+
- 学习中每 20-30 分钟进行一次主动回忆
- 无 `--plan` 的 `/learn` 学习会话插入主动回忆检查点；`/learn --plan` 仅规划章节路线，不启动练习或计时

### 2. 费曼技巧 (Feynman Technique)
- 用最简单的语言解释一个概念
- 如果无法简化，说明理解不足
- 记录在笔记中，反复迭代

### 3. 交错练习 (Interleaving)
- 混合不同主题比集中练习效果好
- `/review` 默认随机排列不同主题的卡片
- 复习时交叉出现不同 material 的卡片

### 4. 具体-抽象交替
- 概念理解需要具体例子和抽象定义交替
- 每条笔记必须包含至少一个示例

## 使用场景

- 从 PPT 学习时：每 5 页停下来闭卷回忆
- 从 PDF 学习时：每章结束用费曼技巧总结
- 从视频学习时：每 10 分钟暂停并重述
