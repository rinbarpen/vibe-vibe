# 源引用规范 (Source Grounding)

## 来源类型先分清

- **教材事实**：来自实际读过的材料内容，使用 `[Source: 材料名, 已核验位置]`。包括真实章名、正文结论、教材依赖和习题编号。
- **用户信息**：目标、基础、已学范围记录为“用户提供”，不硬配教材引用；未知写“待确认”。
- **助手安排**：学习目标、阶段、重点问题、完成标准用 `[规划建议]`；推荐顺序用 `[推荐顺序：沿用目录]` 或 `[推荐顺序：推断]`。不把这些说成作者要求。
- **知识性补充**：独立于教材的解释标 `[unverified]`，或给出另行核验的真实来源；置信度不代替核验。

规划不是每一行都附教材引用，而是每项教材事实和对应章节可回溯；用户偏好与助手安排不伪造出处。

## 引用格式与定位

```text
[Source: 材料名, 位置标识]
```

| 载体 | 定位示例 |
|------|----------|
| PPT | `[Source: ML-课件.pptx, P15]` |
| PDF | `[Source: 教材.pdf, PDF页序 18, 印刷页码 5]` |
| PDF 页码未知 | `[Source: 教材.pdf, 第二章 概率基础]`，另标“页码待核” |
| EPUB | `[Source: 教材.epub, 第三章 线性模型, 第2节]` |
| Video/Audio | `[Source: Lecture3.mp4, 15:23]` |
| Web | `[Source: https://example.com/article, 小节标题]` |
| Image | `[Source: architecture-diagram.png]` |

- PDF 页序从 1 开始，与书页印刷页码分别核验；只有一种已知时只标该项，禁止直接假定两者相等。
- 若只读过目录，可引用“目录（PDF页序 X）”证明章名及目录所列页码，但标注“正文位置待核”；这不证明对应正文或习题已经检查。
- 页码都未知时使用实际读到的章/节标题，不推算页码。章节标题也未识别时，标“待补”，不补造“第 N 章”。
- 教材练习只引用实际题号、标题或位置；未检查写“习题待核”，助手自拟任务单独标注，不冒充教材题目。

## 多来源与覆盖状态

每份材料保留独立路径和索引；文件同名或主题相似不等于内容对应。对应关系仅在标题、正文或课程说明有依据时建立。

同一断言有多份材料支持时分别引用：
```text
[Source: ML-课件.pptx, P15; 教材.pdf, PDF页序 53, 印刷页码 42]
```

材料地图和路线保留“完整/部分索引、已读范围、OCR 存疑、缺页/待补”状态；抽查章节不代表已验证整书。引用的本地材料须能在 `materials/` 下回溯，网页须保留原始 URL 与本地保存路径（若有）。

## 置信度与检查

| 标记 | 含义 |
|------|------|
| `[confidence: high]` | 已与材料核对的内容 |
| `[confidence: medium]` | 有材料依据但存在解释/识别不确定性 |
| `[confidence: low]` | 低把握的补充/解读，明确列出限制 |
| `[unverified]` | 无已核验源材料支持的知识断言 |

- 不编造来源、页码、章节、习题编号，不引用与内容不匹配的位置。
- 已有引用发现错误时明确更正并保留更正说明，不无理由删除来源。
- 每条原子笔记有 source field，闪卡有来源；`MATERIAL_INDEX.md`、`LEARNING_PATH.md` 用各自模板，不套用原子笔记定义/示例/闪卡要求。
