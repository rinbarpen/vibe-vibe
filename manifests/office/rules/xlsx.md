# Excel 制作与验收

先加载 `.agents/skills/omnisheet/SKILL.md` 确认场景/数据模型/布局，再进入底层 XLSX 引擎；图片形式的数据绘图先经 `.agents/skills/omnidraw/SKILL.md`（含 matplotlib）。

先加载 `.agents/skills/anthropics-skills-xlsx/SKILL.md`、`office/xlsx/CLAUDE.md` 和共享质量/文件保护规则。CSV 用于数据交换，不承诺保留公式、图表、格式或多工作表。

## 图表与宏决策

- 分别记录 `chart_decision` / `macro_decision`（yes/no/pending）和用户确认来源/本次范围。未明确时主动询问，可合并为一问；复用已有明确要/不要，不重复问、不以沉默或模板推荐作同意。pending 时继续非图表/非宏工作，未决范围不标通过。
- 新增图表 yes 后明确指标、类型、位置和源范围；no/pending 不新增或重建图表，也不改用图片绕过。既有图表默认保留，按已确认编辑范围更新数据引用与验证；宏若创建图表也经过同一确认。
- 宏支持制作/保留/修改/显式调用：`.bas` / `.cls` 源与 `.xlsm` / `.xltm` 真实宏包分开管理。调用前确认用途、入口、目标簿/表/范围、触发和输出；用户已明确的任务范围直接记录，不反复批准。打开输入不自动运行宏，不修改全局信任。
- `.xlsx` 不承载 VBA；`keep_vba=True` 仅保留而非执行/完整保真，源码或示例编译项目不证明本次新宏已经编译/运行。按 `office/xlsx/references/charts-and-macros.md` 分别记录静态、保留与实际 Excel 执行证据。

## 数据与公式

- 区分原始输入、假设和计算结果；原始数据可为常量，派生计算使用公式，保留来源、单位、日期和口径。核对跨工作表汇总和图表使用同一份数据。
- 以公式模式打开用于编辑的工作簿；`data_only=True` 仅用于读取已计算缓存，禁止保存以该模式打开的对象，避免公式被数值替换。
- 保护既有公式、命名范围、格式、数据验证、图表、合并单元格及引用。检查被所用库不支持的特性，在副本中验证保留情况。
- 不为缺失数据编造零值。检查空值、重复、类型、日期、错误值、总计及引用范围；显式区分百分比与百分点。

## 重算与覆盖

- 保存并真实重算副本；非宏 `.xlsx` 可用 `bash office/xlsx/scripts/recalc.sh WORKBOOK.xlsx`，使用独立输入/输出目录和隔离 LibreOffice profile，校验新产物与公式缓存，而非仅检查返回码。当前 recalc/render 的表格路径仅支持 `.xlsx`；含宏文件保留 `.xlsm` / `.xltm`，采用实际 Excel 保真路径，缺环境则 pending，不经转 `.xlsx` 丢宏。
- 将最终工作簿以公式模式和 `data_only=True` 只读模式分别打开，对照全部工作表公式与缓存，检查错误值、空缓存及关键业务数值；空缓存或不受支持的公式记录为待验收，不声明已重算。
- 对关键计算使用可复现的独立预期值核对；检查全部工作表（含隐藏工作表）的数据/公式，记录工作表清单、公式位置及检查结果。
- 明确所有交付视图/打印区域并渲染审查列宽、截断、分页、数字格式、图例和图表。未声明打印区域时先选择并记录预期交付视图，而非假定默认打印正确。
- 将最终文件哈希、源数据、公式和数值证据、重算记录、全部工作表及打印视图覆盖交给 `office-qa`。缺重算或渲染条件时保留草稿并列明待验收项。
