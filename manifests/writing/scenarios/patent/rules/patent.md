# Patent — 中国专利编写

读取 [专利执行指南](../../../references/patent-guide.md) 与项目已有简报、交底、文稿和账本。具体阶段加载 `.agents/skills/chinese-patent/` 中相应子技能；图形路由读取 `.agents/skills/omnidraw/SKILL.md`。项目路径以项目根目录为基准。

1. 只写有材料支持的技术方案。现有技术的检索结果、用户事实、拟议方案、假设及待核实项分开；“未检索”不写成“已证明新颖”。外部上传未公开技术材料前先取得该动作的明确决定。
2. 规划提出类型、必要/附加技术特征、独立/从属权利要求结构、实施例与附图清单；保护范围或类型存在真实取舍时提交具体版本供用户决定。已有有效决定直接复用。
3. 维护权利要求—说明书—实施例—附图的支持矩阵和术语表。关键特征缺实现细节时等待事实补充；不用语言润色掩盖缺口，新增内容返回规划复验。
4. 附图保存可编辑源及导出图，核对技能约定的黑白、中文/符号、标记和图文引用；正文以技能 HTML 模板组织，权利要求与摘要作为同一源稿的明确部分。所需图缺失或引用错误先返工。
5. 审阅区分必须改和建议改；必须改清零且证据齐备后才导出交付版。仅审阅任务直接交付问题报告，不强制先画图或重写。导出后重新打开 DOCX，核对文字、图片、公式、分页；记录实际预览覆盖与缺项。
6. 交付为“供确认/专业审阅的草稿包”，不是已申报或已授权的证明。对外发送、正式申报及保护范围最终取舍另记真实决定；本场景不执行申报。未完成事项保留 draft/waiting 状态，不标 reviewed/delivered。

各阶段的返回点、等待与回退按指南执行。图和检查脚本验证结构与资源，不代替技术事实、保护范围与实质内容审阅。
