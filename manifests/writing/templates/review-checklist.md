# 标书候选版本审查

- 审查对象、版本及 SHA-256：待补
- 招标/补遗有效版本：待补
- 审查者、方式与时间：待补（自审与独立审查分开记录）

| 维度 | 检查内容 | 结果与证据定位 |
| --- | --- | --- |
| 来源完整 | 正文、附件、澄清/补遗均纳入；OCR 对照原页 | 待查 |
| 条款覆盖 | 复合要求拆分；无漏项、无跨标段混用 | 待查 |
| 否决/资格 | 每项逐一核实有效性、适用主体、期限与证明材料 | 待查 |
| 评分项 | 每项有具体方案、证据和章节定位；不把覆盖率当作得分 | 待查 |
| 事实与数据 | 名称、人员、资质、业绩、数值/单位/日期一致 | 待查 |
| 方案可落实 | 任务、责任、工期、质量、风险与验收形成闭环 | 待查 |
| 商务与价格 | 分项与总额、币种/税口径、承诺和偏离经责任人核对 | 待查 |
| 格式和原生文件 | 规定表单、编号、目录、页码、交叉引用及可编辑性 | 待查 |
| 全量页面 | 当前成品逐页渲染审阅，无空白/截断/缺字，证据覆盖全页 | 待查 |
| 长任务恢复 | 章节检查点绑定正文/来源/前置章/素材版本，半章进度与下一动作已保存 | 待查 |
| 补充项闭环 | 必需材料、内容与图文缺口已核实，provided 与 verified 区分 | 待查 |
| 图文回流 | 成品/图源/预览/题注/正文引用齐全，共享素材无重复或失配 | 待查 |
| 资料与引用 | 用户原件/提取副本/来源版本可追溯，页码/条款定位、事实支持与用途已核对 | 待查 |
| 多轮修改 | 实际当前稿已快照，用户手改保留，差异及直接/依赖章节复验完成 | 待查 |
| 换版与交叉引用 | 新资料未自动替代旧依据，脚注/图表/章节编号、目录与页码已更新 | 待查 |
| 实际页数 | 指定模板下实际计数，计入范围与上限/目标一致；预算不作为实测 | 待查 |
| 提交要求 | 签章位、附件、份数、格式、命名、期限和平台要求 | 待查 |
| 决定与归档 | 真实定稿决定绑定当前版本；外发/提交另有明确委托 | 待查 |
