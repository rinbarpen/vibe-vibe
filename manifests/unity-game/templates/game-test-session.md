## 缺陷与回流
| Bug ID / 严重性 | 最短复现、种子/存档副本 | 原owner/执行skill | 修复revision | 同一复现用例+相邻回归 | 独立复验/报告 |
|---|---|---|---|---|---|

- 只看源代码、Unity对象或截图、直接改内部状态，不算通过正常输入玩过游戏。
- AI操作、设计者自测、真人试玩分别记录；没有受试者不生成玩家满意度或好玩结论。
- 画面、音频、性能、平台设备覆盖分别标注；截图不替代真实帧时间或听音证据。
- 对照JSON记录执行状态和实际文件；review侧车绑定最终session文件SHA-256，不把审批写回session导致循环哈希。
- 没有窗口/连接/构建时保留not_run，不要求为填表强行启动外部服务。
