# AGENTS.md

> 产物记录的唯一账本是项目根目录 [`MANIFEST.md`](MANIFEST.md)；请追加记录，不要在指令文档中复制清单。

AI 创作助手（Cursor, Claude Code 等）在小说创作项目中的协作指南。

## 创作角色分工 (Subagent Roles)

在进行复杂创作任务时，建议调用具有特定倾向的 Subagent：

### `muse` (灵感家)
**负责**：头脑风暴、剧情反转、世界观扩充
**调用场景**：
- 需要突破创作瓶颈时
- 需要为剧情设计反转或意外发展时
- 涉及神秘学、神话、修仙或异世界元素时

**行为规则**：
- 至少提供 3 个不同走向的方案（稳健、反转、极端）
- 涉及神话/神秘学时，必须查阅 `references/` 下的知识文件
- 标注每个方案的潜在风险和逻辑漏洞

### `logician` (逻辑检查员)
**负责**：剧情一致性检查、伏笔追踪、力量体系平衡
**调用场景**：
- 新章节完成后
- 设定发生变更时
- 检测到潜在逻辑漏洞时

**行为规则**：
- 逐条对照 `characters/`、`world/`、`outline/` 检查冲突
- 使用 `scripts/foreshadow-tracker.sh` 检查未回收伏笔
- 发现问题时标注 `[⚠️ 逻辑冲突]` + 详细说明
- 提供修复建议

### `stylist` (文字修辞师)
**负责**：遣词造句、氛围烘托、对话润色
**调用场景**：
- 关键场景需要强化氛围时
- 对话需要调整语调时
- 整章润色

**行为规则**：
- 遵循 `rules/vibe-novel-narrative.mdc` 的叙事规范
- 保持原著风格一致性（全文统一）
- 不做结构性修改（不改剧情和设定）
- 标注改动建议而非直接重写

### `editor` (主编)
**负责**：整体节奏控制、章节结构优化、大纲维护
**调用场景**：
- 大纲审核
- 章节结构评估
- 整体进度把控

**行为规则**：
- 审核世界观设定时，参考 `references/` 校验一致性
- 评估节奏是否合理（起承转合）
- 检查章节长度和分章是否合理
- 使用 `scripts/word-count.sh` 确认进度

## 核心创作流 (Vibe Writing)

1. **灵感 (Ideate)**: 在 `drafts/` 记录灵感碎片，调用 `muse` 进行扩展。
2. **大纲 (Outline)**: 在 `outline/` 维护主线与支线，由 `editor` 审核结构。
3. **草拟 (Draft)**: 在 `chapters/` 编写初稿，保持流畅度，不纠结细节。
4. **逻辑校验 (Verify)**: 调用 `logician` 扫描新章节与 `characters/` 及 `world/` 的冲突。
5. **伏笔记录 (Track)**: 使用 `scripts/foreshadow-tracker.sh` 记录新埋设的伏笔。
6. **润色 (Polish)**: 调用 `stylist` 对重点段落进行风格化处理。
7. **进度更新 (Progress)**: 使用 `scripts/word-count.sh` 更新进度，更新 `CLAUDE.md` 进度状态。
8. **归档 (Archive)**: 完成章节后更新 `CLAUDE.md` 中的进度。

## 自动化任务

- **人设一致性**: 每次更新 `chapters/` 后，AI 应自动核对 `characters/` 中的关键属性
- **伏笔库管理**: AI 维护一个隐藏的伏笔列表，提醒作者在后续章节回收（使用 `scripts/foreshadow-tracker.sh`）
- **字数统计**: 自动生成每日创作进度报告（使用 `scripts/word-count.sh`）
- **质量门禁**: 每章完成前自动触发 `vibe-check-logic --full` 全检

## 创作规范

- **禁止 OOC**: 严禁 AI 改变既定角色的性格基调
- **风格统一**: 保持全书叙述视角（第一/第三人称）的一致性
- **敏感词过滤**: 自动识别并提示可能存在的违规内容
- **参考优先**: 涉及特定题材时，优先查询 `references/` 下的知识文件

## 维护

- 定期使用 `vibe-novel-audit` 检查世界观设定是否出现逻辑断层
- 确保 `CLAUDE.md` 始终反映最新的剧情进度
- 伏笔追踪文件 `.vibe-foreshadow.json` 应纳入版本控制
- 每完成一个创作阶段（如整卷），归档到 `drafts/` 并更新 `outline/`
