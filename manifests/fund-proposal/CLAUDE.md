# CLAUDE.md (Fund_Craft_Pro 专用)

> 产物记录的唯一账本是项目根目录 [`MANIFEST.md`](MANIFEST.md)；请追加记录，不要在指令文档中复制清单。

针对中文基金申请书（基金本子）撰写与修改的项目上下文管理。

## 常用指令

| 命令 | 描述 |
| :--- | :--- |
| `/init` | 启动向导，建立项目基准 |
| `/brainstorm` | 选题与 Gap 分析，提炼科学问题 |
| `/outline` | 构建逻辑闭环大纲 |
| `/draft [章节]` | 章节撰写，预留图表占位符 |
| `/polish [文本]` | 学术润色，优化逻辑连词 |
| `/review` | 毒舌评审，逻辑挑刺并给出 Reject 理由 |

## 项目结构

```
<root>/
  draft/           # 各节草稿（如 01_立项依据.md, 02_研究内容.md）
  outline/         # 提纲、创新点清单、关键科学问题
  refs/            # 参考文献与引用（.bib, refs.md 或 list）
  assets/          # 技术路线图、表格、图片等
  final/           # 定稿或导出文件（PDF/Word）
```

## 关键文件

- `outline/skeleton.md` - 基金本子整体大纲
- `outline/innovations.md` - 核心创新点列表
- `outline/key_problems.md` - 拟解决的关键科学问题

## 核心规则 (Red Lines)

- **防止幻觉**: 绝不捏造参考文献或实验数据。
- **严守概念边界**: 
    - **研究内容** (What)
    - **研究目标** (Why/Result)
    - **关键科学问题** (难题)
    - **技术路线** (How)
- **行文风格**: 书面、客观、严谨，短句 + 逻辑连词。
- **排版规范**: 中英文、数字之间加空格。

## 协作流

1. **初始化 (/init)**: 建立项目基准。
2. **头脑风暴 (/brainstorm)**: 提炼科学问题。
3. **架构设计 (/outline)**: 确保逻辑闭环。
4. **分节撰写 (/draft)**: 高质量学术产出。
5. **润色优化 (/polish)**: 提升信息密度。
6. **毒舌评审 (/review)**: 逻辑挑刺与改进。
