# 自适应主动学习

以 `references/metacognitive-framework.md` 为底层：成功提取后可用 JOL，提取受阻时可用 FOK；按 EOL、完成信心及真实错因调整策略和相对投入。仅同范围证据支持预期/实际比较，缺证据记未评估；低信心但已达标时校准自评而非自动加练。策略实施后回溯实际效果，无效时换策略/补先修/重排任务，保留断点及尝试日志；目标、范围或预算变更等待用户决定后恢复。

遵循 `references/tutor-interaction.md`。主动回忆是可选方法，不是每轮强制提问；用户要完整讲解/直接答案/先别提问时照其需求处理。去掉固定分钟/页数的检查点，不把聊天轮次或消息间隔当实际学习时长。

- 需要检查当前概念时给一个问题，等待真实作答；部分正确先保留正确部分，再给针对性提示。
- 用户不会时可换具体例子、拆一步或简化前置，不把答案直接当用户已学会。
- 费曼重述、具体与抽象交替、交错练习根据内容选择，不强迫所有用户使用同一方法。
- 无卡片的 `/review` 也可围绕笔记、错误和问题复习；有卡片保留 SM-2，到期优先而非无条件随机。
- `/learn --plan` 仅规划，不启动练习或计时；自然语言的系统学习可在简短导学后开始一个单元。
- 学前读取 `projects/<教材或主题>/LEARNING_RECORD.md` 当前辅导状态，按 `references/learning-records.md` 保存待答题、实际作答/反馈和暂停任务。未作答/未评估不写成通过，一题不推断整章掌握。
- 用户原文与助手摘要分开；真实增量在本轮回复结束前保存，不等结束口令。普通教学低打扰，首次建档/阶段总结/明确记录时提示，失败立即说明。
