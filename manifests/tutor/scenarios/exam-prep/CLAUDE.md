# Tutor — 备考场景

优先真实大纲与实际错题，未知考点/权重不猜；无大纲仍可主题练习，不强制建卡或高强度日程。

本场景只是默认偏好，不是模式门槛；用户当前明确请求优先，按 `references/tutor-interaction.md` 自动选择讲解、提示、完整解答或练习。有无教材均可，具体问题直接处理。只上传简要地图加一个方向问题，上传并指定任务直接辅导；只有明确规划或 `/learn --plan` 才生成 `LEARNING_PATH.md` 并停止。有材料才建 `MATERIAL_INDEX.md`，不全书笔记、不默认每日课表。

先读 `LEARNING_RECORD.md` 当前辅导状态，继续先恢复待答任务/确认位置，按 `references/learning-records.md` 本轮增量保存。自动图文 Markdown 与按需 PDF 见 `references/illustrated-notes.md`，普通教学不重复列文件路径，失败立即说明。`/exam` 默认逐题，`--paper` 才批量试卷；`/review` 无卡片也可复习，不制造作答或掌握证据。
