# /track

## Purpose

以 `projects/<教材或主题>/LEARNING_RECORD.md` 为个人学习记录入口。即使没有闪卡，也能查看学到哪里、留下的笔记/问题和下一步。记录约定见 `references/learning-records.md`。

## Usage

```text
/track                      # 当前学习项目的进度与记录
/track --scope week         # 有实际日期记录的本周活动
/track --scope month        # 有实际日期记录的本月活动
/track --scope domain pdf   # 按材料载体过滤
/track goal set <goal>      # 保存用户提供的学习目标
/track goal list            # 查看已记录的目标
```

## Execution Logic

1. 确定当前项目，读取 `LEARNING_RECORD.md`，并关联存在的同目录教材地图和学习路线；无教材不要求创建地图。多个候选且对话未选定时请用户选择，不将不同教材记录混合。用户明确要求跨项目总览时按项目分组。
2. 默认只展示，不改写日志或完成状态。无记录时明确显示“暂无学习记录”，展示已存在的路线/索引和可记录的信息，不回填虚构历史。
3. 输出学习条件、章节状态、用户原文笔记和问题（或其链接）、助手摘要、待解决问题、最后确认位置及建议下一步。状态“已读/已练习”与“掌握度”分开，不以助手生成的笔记数判断掌握。
4. `goal set` 将用户原话目标保存到学习条件快照，并追加条件变更记录；不自动附加截止日期或改动已有学习日志。`goal list` 只读现有目标。自然语言“记住这条笔记/这个问题”也按记录规范即时保存。
5. 有实际复习日志/卡片时才附加卡片量、到期数量、实际完成数和复习数据指标。卡片调度状态不等同于整章掌握。无数据时写“暂无数据”，不把示例数字当结果。
6. 章节覆盖优先显示各状态的实际计数；只有已知完整统计范围和分母时才展示比例并说明口径，缺少记录的章节不直接算已读或已完成。时长仅累计用户提供或工具实际记录的数据，不从消息数、页数、文件时间估算实际学时。

## Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--scope` | all | 范围：all/week/month/domain；无日期的记录不擅自归入某周 |
| `goal set <goal>` | — | 保存/更新目标，并保留变更依据 |
| `goal list` | — | 展示已保存的目标 |

## Report Sections

- **教材与目标**：当前项目、用户目标、基础与偏好，未知项明确标出。
- **章节覆盖**：索引单元 ID、真实章节、学习状态、独立掌握度与证据；说明统计范围是否完整。
- **我的记录**：用户笔记/问题与助手整理分区展示，链接到记录条目；待解决问题单列。
- **从哪里继续**：最后确认位置、建议下一步；没有确认位置时不猜测。
- **复习附录（有数据时）**：实际卡片/复习统计与统计口径，不编造学习时长或掌握率。

## 当前辅导状态

只读显示待答问题、最近真实作答/反馈和暂停任务引用，方便用户判断从哪继续。无新状态区的旧记录仍按原位置和日志展示；不因查看创建状态区或写迁移标记。普通教学的低打扰保存不影响用户明确查看时获取路径和详细记录。
