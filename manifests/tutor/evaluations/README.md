# Tutor 教学与教材规划行为验收

这些案例用于安装本 manifest 后的**助手会话验收**，不是教材解析后端或自动模型评测。CLI 单元测试只验证安装/资源契约。手工记录助手原始输出、使用工具、文件产物和逐项结论；没有真实会话输出时不得记为模型端到端通过。

## 样例事实

- `fixtures/textbook.pdf`：5 页小型英文教材。PDF 页序 1 为封面、2 为目录；章 1/2/3 分别位于 PDF 页序 3/4/5，印刷页码分别为 1/2/3。第二章正文明确要求先理解第一章变量类型；第三章只有检查清单，没有编号练习。生成源为 `fixtures/textbook.json`。
- `fixtures/companion-slides.md`：**幻灯片提取文本样例，不是 PPTX 文件**。Slide 2 明确对应教材第二章；Slide 3 的 Checking 标题不构成与教材第三章对应的充分证据。
- `fixtures/partial-ocr.txt`：**部分 OCR 提取结果样例，不是扫描 PDF**。仅一个可确认章名；目录缺失、页码存疑。用于验收处理不完整提取结果的行为，不验证 OCR 准确率。

## 会话案例与通过标准

### 1. 上传后自动分析、保留学习会话

在空学习项目中上传 `textbook.pdf`，不先输入 `/learn --plan`。

- 先读目录/必要页面，展示 3 章地图，记录可验证的页序和印刷页码。
- 简要展示结构与待补，再问一个学习方向问题；不先收集完整学习条件，不追问每天几小时或完成日期。
- 在用户选择学习单元之前，`notes/atoms/`、闪卡目录不出现全书笔记或卡片。
- 回复“请先规划整本教材；知道算术，不熟悉变量类型；还没学过”，复用这些条件并生成双产物，格式见模板。
- 路线包含 3 个真实章节，每项有目标、定位、重点问题、真实习题或待核说明、完成标准。
- 第二章依赖第一章可以标为教材明确依赖，但需要核验正文；仅读目录时只能作为建议顺序。
- 第三章不能出现虚构的“练习 3.1–3.5”，可标未发现编号练习或另列助手自拟检查任务。
- 之后单独输入 `/learn Means --material materials/pdf/textbook.pdf`，应进入学习会话，不只再次交付路线。

### 2. 已知条件不重问、多材料不误合并

先说明“希望学会数据类型与均值；已学完第一章”，再同时提供 PDF 和配套提取文本。

- 复用目标与已学范围，仅补问缺失基础；不因为学过就自动认定掌握或跳过。
- 两份资料分别索引；Slide 2 的明确配套说明可验证，Slide 3 仅记可能相关/待核。
- 所有限定范围外章节列为范围外，不把删减误报为全书覆盖。

### 3. 缺目录、部分 OCR、页码未知

将 `partial-ocr.txt` 作为当前可用的提取结果，并说明原扫描件暂无更多可读内容。

- 索引标 partial，只保留可验证章名和已读片段；索取目录或必要页面。
- 不根据常见课程补出其他章；不把识别不清的页码写成真实页码。
- 用户要求先规划时，可给部分路线草案；基础、覆盖缺口和未知定位明确标注。

### 4. 页码体系与原有记录

对 PDF 目录所列位置和实际正文页序逐项核验，并在已有路线里写入用户记录后重新请求规划。

- PDF 页序 3 与印刷页码 1 同时保存，目录页引用不得冒充已读正文引用。
- 更新路线保留用户记录与已确认选择，不全量重提取教材。
- 不生成每日/每周课表，明确规划后不自动教学或创建后台持续排程。

### 5. 保存我的原文、问题与真实进度

在已索引教材项目中输入：

> 我读完了第一章，到第二章开头。记下我的原文笔记：平均数也能用来概括喜欢的颜色。这是我的疑问，还没搞懂为什么不合适。练习我还没做，下次从第二章开头继续。

- 实际写入该项目 `LEARNING_RECORD.md`，回复路径；不能只说已记住而没有文件。
- 用户原文完整保留；教材核验/纠错放助手摘要，不静默把原文改成正确答案，也不将原文当教材事实。
- 第一章仅按用户自报标已读；未作答的练习和未测掌握标未作答/未评估，不自动标整章掌握。
- 当前位置关联真实单元；用户确认的章名与工具验证的页码依据分别记录。没有实际时间/时长不补造。

### 6. 新会话续学、只读查看与历史保护

在新对话只输入 `/study --next`，之后查看 `/track`：

- 先读个人记录，复用已知目标/基础，从已确认的第二章开头恢复，不再次要求用户从头说明，不自动跳第三章。
- 可回顾遗留问题；没有真实作答时仍保留未作答/未评估。没有记录或多项目歧义时先确认，不猜位置。
- `/track` 无闪卡也能显示章节状态、个人笔记、问题及位置，默认只读，不追加一次虚构学习事件或更新文件时间。
- 用户纠正学习条件或原文时追加关联更正，保留历史；重新规划/导入及安装 `--force` 不清空个人记录。
- 用户明确要求删除某条原文时，只处理指定范围，不为更正留痕再次复制该条应删除内容。

### 7. 具体学习自动生成图文 Markdown

用户基于已有教材地图开始具体章节学习，不额外发“做笔记”指令：

- 本轮结束前实际生成 `notes/summaries/<主题>/<单元ID>-<章节名>.md`，只整理本轮知识增量，不假称整本已学。
- 短定义和少量事实用文字；涉及类型判断、分支、依赖或长且抽象的关系时，使用适当图解并给简短读图结论，不把所有段落机械装入框。
- 复杂关系图在 `notes/assets/<主题>/` 有真实 SVG/PNG，MD 用可解析的相对图链；图有 alt、标题、图注、来源与示意/推断说明，可编辑图源保留。
- 只有 Mermaid 代码或失效图链不算图文完成；更新已有笔记保留用户手改和原文，个人原文仍单独记录，不把助手笔记算用户掌握。
- 单独 `/learn --plan` 或只上传教材仍不生成全书笔记。

### 8. 图文 PDF 与原件保护

对已有学习笔记说“导出 PDF”，或对具体学习使用 `--export pdf`：

- 实际调用本地导出器并交付 PDF；纯转换不重新教学或改进度，不默认夹带个人学习日志。
- 用 `pdfinfo` 检查可读页数，用 `pdftotext` 检查正文；另将页面渲染查看，确认中文可读、图片可见、图注与表格未裁切，不能只靠 PDF 文件头判断成功。
- MD、图像和图源保持原样；默认保留已有 PDF，明确要求覆盖时才替换。渲染失败或缺少 Mermaid 渲染器不损坏已有 PDF，不把未渲染代码当图。
- 在含空格路径及中文标题下测试，资源仅使用本地文件，不自动请求 CDN。

## Tutor 对话补充案例

下列输入须在实际助手环境按顺序发送并保存原始输出/工具轨迹；预期描述不等于已执行结果。主实现助手编写的示例、静态检查或脚本伪响应不得冒充独立会话通过。

### 9. 无教材的直接问题与完整讲解

在没有材料/路线的空项目输入“为什么颜色不能求平均？完整解释，先别问我”。应直接解释类别标签与有意义数值的区别，不要求上传/填写基础，不附加必答题；自动写通用知识 Markdown，不造教材章号/页码或逐句贴 unverified，首次建档提示路径。

### 10. 宽泛目标、已知条件复用

输入“我想系统学统计，只会算术”。只补问确实影响起点的信息；足够时简短导学后开始一个目标，不只交路线后停住，不反复问已知基础。用户改说“只规划，先别教”则只规划并停止；无教材不创建假地图。

### 11. 上传并指定任务

上传 textbook.pdf 并说“只解释第二章的均值例子”。定位相关正文，直接辅导，索引可部分覆盖；不先收集目标/基础/已学章节或倾倒全书路线。保留真实 PDF 页序与印刷页码区别。

### 12. 提示、错误与直接答案切换

请求一道题后说“不会，提示一下”。先给可操作提示，不显示完整答案；再提供一个错误/部分正确回答，反馈针对实际内容。最后说“直接给完整答案”则完整解答，不强制继续反问；记录助手示范而非用户答对。

### 13. 逐题测验与试卷分离

输入“考我三道平均数的题”。一次一题，无正确项标记/解析；--count 只控制题数。未答说“继续”时仍恢复当前题，不自答推进。另请求“生成三题试卷，附独立答案”或 --paper，才批量输出两个文件，题面不泄露答案。未作答不填分数/覆盖百分比。

### 14. 没有卡片也能复习

保留已有笔记和错误记录，确保卡片为空，输入“复习一下刚学的”。应按真实问题/笔记回顾或逐题练习，不要求先生成闪卡、不写虚假 SM-2 调度。用户要求“只总结，不出题”时只回顾。

### 15. 新会话恢复待答题

实际出一道题，确认 LEARNING_RECORD.md 保存题目、必要条件/选项及待作答。开启不带原聊天的新会话只输入“继续”。先读取文件并恢复原题/提示，不提前给答案、不出下一题；实际作答后保存具体反馈。记录没有新状态区时仍能按旧确认位置恢复。

### 16. 换题与暂停任务

未答题时输入“先不做了，讲另一个概念”。切换焦点、保留旧题为暂停任务，不标完成；再请求原题时恢复相同题干。多个项目存在歧义时只问必要选择，不跨项目保存。

### 17. 低打扰与失败可见

首次建档提示路径，随后普通教学仍有实际文件增量，但不每轮列笔记/图/日志路径；阶段总结或“记下我的原话”时再给相关路径。模拟写入失败，必须立即说明未保存项目，不口头声称已记录。

### 18. 查看/导出不改变状态

存在待答题时执行 /track 和导出已有笔记。核对所有 MD/记录/图源内容和时间戳保持不变；只新增选定 PDF，保留旧 PDF 的覆盖保护，不要求回答待答题或重新询问基础。个人原文日志不默认进入 PDF。

## 验收边界

安装、升级/恢复、来源标签和资源引用可自动测试；教学适应性及新会话恢复的质量必须用实际助手会话记录结论。缺真实会话或独立上下文时记“未执行”，不能用固定文本样例代替。
