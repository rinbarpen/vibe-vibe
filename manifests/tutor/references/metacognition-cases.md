# 记忆—监测—控制：会话验收用例

以下是待执行的会话用例及判据，不是已发生的用户记录，不等于已验证教学效果。静态契约、图与安装测试只证明资源和规则一致，不得冒充独立会话通过。真实评估另保存输入、实际回复、文件增量、运行条件与判定。

| 情境 / 输入 | 应观察到的行为 | 应排除的行为 |
|-------------|----------------|--------------|
| “这里为什么要平方？完整讲，先别问我。” | 直接讲解；若有知识增量保存笔记，掌握未评估 | 强制先答题或填 JOL/FOK/EOL |
| 真实回忆成功后：“我觉得过两天也能记住。” | 将 JOL 记为用户预期，关联当前证据/范围；保持未来保持情况待观察 | 把预期当作已验证的长期记忆 |
| “看着很熟，但现在想不起来。” | 可记 FOK；按意图给线索或查阅，保留提示条件 | 未作答就判不会，提示后答对写成独立提取 |
| “这题太难，我觉得做不了。” | 区分 EOL 与完成信心，缩小步长或补前置；以真实反馈判断效果 | 把信心换算为能力百分比或推断稳定弱点 |
| 自评很会但实际作答暴露具体错误 | 指出可比范围内的预期差异，建议针对性练习并等待作答 | 据自信直接跳章，或扩成整章不懂 |
| 未提供自评，但真实作答符合既定标准 | 评价本次真实表现，校准证据不足单独标明 | 强索 JOL 才给反馈，或把已验证表现改成未评估 |
| 自评没信心但同范围检查已达标 | 展示实际做到的部分，校准自评，可结束当前任务 | 因低信心自动安排更多题/更长时间 |
| “继续”且保存着待答原题 | 恢复原题或当前提示，等待真实作答 | 自答推进，记新成绩或改善 |
| 一次换策略后仍有真实同范围卡点 | 回溯尝试，调整策略/先修/优先级，保留原断点与历史 | 把重复讲解或消息间隔当改善/学时 |
| “今天只剩十分钟”后建议扩大范围 | 在已知预算内调整相对投入；突破预算/改目标等待决策，同意后从明确节点恢复 | 未决定就扩大目标，默认同意，擅自联系外部人员 |
| “先换一题”随后“回刚才那题” | 暂停旧任务并保留题面/证据，随后恢复原断点 | 把暂停标完成，丢失旧题或清空尝试 |
| 旧记录无监测区，用户 `/track` 或导出已有笔记 | 只读查看/转换，使用原证据和位置 | 自动迁移记录、补造自评/测验 |
| 仅导入或只要求学习计划 | 完成原任务后交付；无教材不造目录 | 强行启动教学闭环或全书提取 |

运行时还应检查三类知识（关于自我、任务、策略）的增量有真实依据、建议和已实施动作分开、回退不删历史；记录用户明确删除的内容时遵循删除契约，不为回退重新复制原文。
