# 自动图文笔记与 PDF 导出

本规范同样适用于无教材的主题讲解；不伪造教材 source，可使用 provenance: general、source: []。本规范用于具体章节学习、讲解与笔记整理，不把教材导入或 `/learn --plan` 扩展成全书摘要。这里的“自动”指助手在发生学习增量的同一轮实际保存文件，不是文件监听器或后台定时任务。

## 1. 章节 Markdown 自动保存

- `/learn`（无 `--plan`）、`/study` 及自然语言章节学习，一旦讲解、讨论或核验形成真实知识增量，在**本轮回复结束前**自动创建或更新 `notes/summaries/<教材或主题>/<单元ID>-<章节名>.md`，不等待用户说“做笔记”。只涵盖本次实际学习范围，不提前提炼整书。
- 初次参考 `.cursor/templates/CHAPTER_NOTE.md.example`；已有笔记先读再合并，沿用材料 ID、单元 ID、文件名和稳定图 ID。没有索引单元 ID 时使用项目内持久的临时 ID 并标“单元 ID 待关联”，不补造教材章号；补索引时建立对应关系，不重新复制笔记。
- 主笔记包含教材与已核验定位、当前覆盖范围、学习目标、概念/解释、必要图解、例题或实际练习、待解问题及相关笔记。未讲过的内容留待后续，不填示例结论或虚假答题记录。知识断言使用 `references/source-grounding.md` 的真实引用；助手生成的例子、示意和推断明确标明。
- 更新已标识的“助手整理（自动更新）”区域（`<!-- AUTO-NOTES:START -->` 至 `<!-- AUTO-NOTES:END -->`）；用户原文/手改段落、附件和其余章节原样保留。已有文件没有此边界时保留全文并追加带日期或单元增量的小节，不整篇重写。遇到用户修改过的助手区域也保留其表述，另加更正或本次补充；没有可靠证据证明是原始助手内容就不覆盖。重复处理同一增量不重复追加。
- 独立、可复用概念按需提炼到 `notes/atoms/`，章节主笔记链接它们；主笔记不是原子笔记列表的简单复制。纯查看、纯导出和无知识增量的闲聊不生成空笔记。
- 用户明确提供的原文笔记或“记一下”请求另存 `projects/<教材或主题>/LEARNING_RECORD.md`，与助手自动知识笔记分开，详见 `references/learning-records.md`。学习记录中的助手摘要只需概述活动并链接章节主笔记；自动笔记不证明用户已读、已练习或掌握。

## 2. 文字、表格还是图

按信息结构与理解成本选择，长度只是参考，不设置每页/每节必须有图的配额。

| 内容结构 | 默认表达 | 选择依据 |
|----------|----------|----------|
| 短定义、少量事实、单一公式及解释 | 文字、列表或公式 | 通常约 150 个中文字以内或不超过 3 个要点，直接说明更清楚 |
| 少量概念的逐项对比 | 表格 | 对齐相同维度；不为“图文并茂”额外画一张图片表格 |
| 算法步骤、操作流程、条件分支、反馈循环 | 流程图 + 短说明 | 显示顺序、分支条件与回路；每条边有明确含义 |
| 层级、组件结构、多概念依赖与长且抽象的关系 | 结构图/概念图 + 解释 | 用节点和有标记的关系帮助理解，不把整段文字塞进框里 |
| 长线性叙述、推导细节、多个例子 | 分小节、分步推导 | 仅对其中确有空间或关系结构的部分加图，避免机械文字转图 |

没有适合绘图的关系时只用文字或表格；用户已要求图解的抽象结构应实际制图，而不是一直写“此处可配图”。不引入材料没有的因果、先修或包含关系；未知关系标 `[inference]`，独立补充按其核验状态标注。

## 3. 每幅图都是实际可见的本地资源

1. 图文件放在 `notes/assets/<主题>/<稳定图ID>.svg` 或 `.png`；Mermaid 等可编辑源用相同 ID 放在同目录，例如 `.mmd`。直接绘制的标准 SVG 本身可编辑，无须另造重复的源文件；已有 drawio 图保留 `.drawio` 并导出 SVG/PNG。同一图更新沿用 ID，不随每次回复新建副本。
2. 已有 `mmdc` 时可用 `mmdc -i SOURCE.mmd -o OUTPUT.svg` 渲染；也可直接创建标准、可编辑 SVG。只使用本地资源，不依赖 CDN、在线图片热链或脚本执行。SVG 使用明确尺寸/viewBox、可读中文字号、普通文本与形状，不把网页 `foreignObject` 当通用 PDF 兼容图。
3. 图形必须有标题、解释性 alt、图注及来源标签；按实际情况注明 `[教材图摘录]`、`[助手示意]` 或 `[inference]`，教材图/依据材料的示意附真实 `[Source: 材料, 定位]`，纯通用知识示意标“通用知识，助手示意”，不造出处。图后加一两句文字结论，使读者即使未看图也能抓住主要关系。摘录教材图保留原图含义和来源；示意图不冒充教材原图。
4. 主笔记用相对自身路径的标准 Markdown 图片链接嵌图。例如 `notes/summaries/统计/U01-变量.md` 引用 `notes/assets/统计/U01-类型.svg` 时使用 `../../assets/统计/U01-类型.svg`。文件名和目录可以含中文；路径留在项目内，随项目移动仍可解析。
5. 生成后实际检查图文件存在、格式有效，并渲染或打开查看文字可读性、连线方向、标签、遮挡与裁切；检查笔记中的每个图链。**只有 Mermaid 代码不算交付可见图**，代码源可以链接，但不以未渲染 fence 代替图片。
6. 当前渲染工具缺失时先尝试可验证的标准 SVG；仍未产出实际图时将该项明确记为“待渲染”，交付已完成 Markdown，不宣称图片或完整图文 PDF 已生成。修好图再导出，保留已有文件。

章节笔记嵌图的结构示例（示例路径不代表已经存在的资源）：

```markdown
### 变量类型及其含义

![图 1：按取值含义区分类别变量与数值变量](../../assets/统计/U01-类型.svg)

*图 1 · [助手示意]，依据 [Source: 教材.pdf, 第一章 变量与类型]；图源：[SVG](../../assets/统计/U01-类型.svg)。*

结论：先辨别变量的取值含义，再选适合它的统计操作。
```

## 4. PDF 按需转换，MD 保留

自然语言“把这份笔记导出 PDF”或助手指令 `/learn <topic> --export pdf`、`/study <path> --export pdf` 触发。`--export pdf` 不是 `vibe` CLI 参数；没有此要求时自动保存 MD/图资源即可，不在每轮另生成 PDF。纯导出已有笔记不触发新一轮学习，也不写虚假学习事件。

在项目根目录运行已安装的真实脚本：

```bash
python scripts/export-notes.py notes/summaries/统计/U01-变量.md \
  --output notes/summaries/统计/U01-变量.pdf
# 有本地中文字体需求时：
python scripts/export-notes.py notes/summaries/统计/U01-变量.md \
  --output notes/summaries/统计/U01-变量.pdf --font /path/to/chinese-font.ttf
```

- 只转换用户选定的学习笔记及其引用图像；多份候选不随意合并，优先本轮章节笔记，仍有歧义时请用户选择。`LEARNING_RECORD.md` 的用户原文、个人日志、目标和进度不自动夹进 PDF；教材源 PDF 不是笔记导出目标。`--plan` 保持轻量章节规划，不为导出预先生成全书笔记。
- 先保存并验证 Markdown 和每幅实际图像，再执行导出脚本。图源单独保留，输入给导出器的是嵌有可见资源的笔记，不是带未渲染 Mermaid fence 的草稿。长表格、公式和中文排版按脚本支持范围检查；无损保留 MD，不用 PDF 替换源文件。
- 默认保留已有 PDF，用户明确同意覆盖后才添加 `--force`；禁止把输出路径设为原 Markdown 或图源。导出失败时报告具体缺项或错误，原文件和原 PDF 保持不变，不以改扩展名、空白文件或错误日志充当成功 PDF。
- 导出后检查有效 PDF、页数/大小、中文文字与图片；渲染代表页，确认没有中文方框、丢图、裁切或未渲染代码块。需要字体时使用本地可用字体或 `--font`；工具不足导致某项未核验就明确说明，不宣称已核验。
- 最终反馈实际保存的 Markdown、图资源和 PDF 路径及本次覆盖范围；只对成功生成且检查过的文件使用“已生成/已导出”。

## 5. 低打扰保存

普通教学核验后静默保存，不每轮重复列笔记/图源/记录路径；首次建档、阶段总结、明确记录请求或导出时反馈相关路径，用户询问可随时给出。保存失败立即说明，不虚报成功。无教材的主题知识同样自动保存 MD，用稳定主题 ID，不为了填模板要求上传。
