# 章节或主题学习路线

用于 `/learn [topic] --plan [--material <path>]` 及自然语言明确规划请求。只做单元级路线（教材章节或建议主题单元），不生成每日/每周课表，不自动启动学习或持续排程。普通 `/learn` 仍是学习会话。

## 1. 材料先行：索引与展示

- 使用当前上传、`--material` 或对话已选材料；复用已有索引，不重复全书解析。
- 读取元数据、目录/书签、章节标题、前言/概览，以及确认结构所需的代表性页面。只为核验必要信息抽样，不批量提取全书笔记、公式或闪卡。
- 从 `.cursor/templates/MATERIAL_INDEX.md.example` 建立 `projects/<教材或主题>/MATERIAL_INDEX.md`，先向用户展示再补问学习信息。
- 材料地图记录：材料名/版本（已知时）、原始路径、类型、章节层级、章节定位、习题位置（已核验时）、已检查范围、完整/部分索引状态与待补原因。
- PDF 页序（从 1 开始）和印刷页码分别标注。若只读到目录所列页码，标“目录标注，正文待核”，引用目录实际位置；尚未核验的正文页码不当成已读来源。
- 无目录时通过可读标题建立部分索引。扫描/OCR 不完整、缺页或标题存疑时保留原文与待核说明，不补造结构。
- 多材料逐份索引；只有章节标题、内容或课程说明提供依据时才建立对应关系，并记录依据。文件名相似不等于内容已匹配。

## 2. 复用上下文，仅补问缺失信息

先读取当前对话与该项目已有 `LEARNING_RECORD.md`，复用其中学习条件、用户原文笔记、未解问题和确认位置，只询问影响当前路线的缺项，避免一次收集整张条件表：

1. 学习目标：希望理解、应用或备考到什么程度。
2. 已有基础：相关概念/技能的实际掌握情况。
3. 已学章节：用户确认学过的教材范围；未确认掌握时仍保留复核建议。

按 `references/learning-records.md`，规划确认时用 `.cursor/templates/LEARNING_RECORD.md.example` 保存用户已明确提供的学习条件；用户纠正条件时更新快照并追加变更。已有日志和原文笔记不覆盖，规划不生成虚构学习活动或章节完成记录。

不重复询问已明确答案，不以每日时长或截止日期阻塞路线生成。未指定范围默认覆盖所选教材；基础未知明确写“待确认”，前置内容保留。用户尚未答复时可交付教材地图及待确认项；用户要求先规划时，按未知基础给出保守草案并明确默认值，不将默认值记为用户回答。

## 3. 用真实章节组成路线

从 `.cursor/templates/LEARNING_PATH.md.example` 生成 `projects/<教材或主题>/LEARNING_PATH.md`，关联同项目的材料地图。路线沿用索引单元 ID 供 `LEARNING_RECORD.md` 关联；调整顺序不随意重编 ID，不将完成标准当作已完成状态。新增材料与重规划保留学习记录和确认位置。

### 阶段与顺序

按“前置准备 → 基础章节 → 核心章节 → 进阶与综合”分组。这些是**助手规划标签**，不是教材章节；每个非空阶段必须落到已确认的真实章节/小节。教材没有独立前置章时，可将准备阶段写为“检查相关基础，来源/补充材料待补”，不得虚构“第 0 章”。不适用的阶段注明原因，不强填章节。

- `[教材明确依赖]`：正文/前言确实写明依赖关系，附已验证引用。
- `[推荐顺序：推断]`：助手依据概念关系调整顺序，写明理由，不冒充作者要求。
- 沿用教材目录时标 `[推荐顺序：沿用目录]`；目录顺序本身不是已证明的先修关系。
- 默认覆盖所选教材范围。路线末尾核对每章是否已安排，已学/暂缓/待补章节单列并说明依据；用户未同意时不自动跳过。

### 每个学习单元

| 字段 | 内容 |
|------|------|
| 学习目标 | 本单元应能解释或完成什么；助手拟定的目标标 `[规划建议]` |
| 材料与定位 | 教材真实章/小节标题，已确认页码或章节标题；链接到索引中的材料 |
| 前置与顺序依据 | 教材明确依赖，或标为推荐/推断的顺序与理由 |
| 重点问题 | 围绕已知章节内容提出的阅读问题；是 `[规划建议]`，不是教材原文 |
| 教材练习 | 仅列实际核验的题号/标题/位置；尚未检查写“习题待核”，教材无习题写“未发现教材习题” |
| 完成标准 | 可观察的解释、推导或练习结果；由助手拟定的标准标 `[规划建议]`，不编造教材评分线 |

如建议自拟任务，与“教材练习”分开写 `[规划建议：自拟检查任务]`，不得给它伪造教材题号。未读正文时不根据章名断言具体定理、公式或习题内容。

## 4. 来源边界与交付

- 教材事实使用 `[Source: 材料名, 已核验定位]`；用户目标/基础/已学范围记为“用户提供”；助手安排使用 `[规划建议]`。不为用户信息或规划建议硬配教材引用。
- 通用知识补充明确标为独立讲解，真正待核实内容才用 `[unverified]`；已核实外部来源可单列。索引抽样不足时标注路线覆盖的局限。
- 在保存前核对：真实章节覆盖、材料逐份索引、定位可回溯、无虚构习题、未知基础未视作掌握、没有日期/时长安排。
- 交付教材地图、章节路线、已保存学习条件的记录路径、待确认/待补清单后停止。待用户选择具体章节再进入 `/learn` 或 `/study`，保留既有复习、闪卡、考试等按需功能。


## 5. 没有教材的主题规划

用户未选择教材时直接按主题设计建议单元，不要求上传，不创建虚假 `MATERIAL_INDEX.md`。`LEARNING_PATH.md` 写明“主题规划，非教材目录”，用稳定主题单元 ID、目标、建议重点/顺序、助手自拟检查任务和完成标准；材料定位不适用，不能补造章号/页码/习题号。基础未知标待确认，不默认掌握。

显式 `--plan` 仍交付后停止；“我想系统学”但未要求仅规划时按 `references/tutor-interaction.md` 简短导学后开始一个单元。只上传不自动生成整本路线，上传有具体任务可先直接辅导。个人原文、证据和历史继续保留。
