# 学习底层框架：记忆—监测—控制

本文件把用户提供的学习流程图落实为 Tutor 的共同教学契约，供自然语言、九个指令和四种场景复用。它是内部组织辅导的框架，不是用户必须填写的量表或每轮必走的问答脚本。当前明确请求与 [交互契约](tutor-interaction.md) 优先决定本轮做什么。

图中的术语在此用于组织学习活动，不作为心理测量或对学习者的诊断。工作流见 [SVG](workflow.svg)、[可编辑源](workflow.json)。图表示规则，不表示实际学习状态。

## 1. 三层结构与三类知识

| 层 | 在辅导中的作用 | 持久化边界 |
|----|----------------|------------|
| 记忆与任务 | 从问题拆出当前可处理的子任务，按目标相关性、先修依赖、当前薄弱证据和用户明确约束判断重要性；在当前任务中调用相关旧知识 | 工作记忆 STM 对应当前任务、待答题、最近反馈与下一步；长期记忆 LTM 的辅助载体是已保存的笔记、历史证据与可选闪卡。文件只是外部记录，不代表学习者脑内记忆，也不等于助手跨会话天然记住 |
| 监测 | 区分“我以为会多少”和“当前证据支持多少”；记录 JOL、FOK、EOL、完成信心及回溯判断的可见依据 | 个人自评、助手暂定判断、实际作答证据分开；缺数据记未评估，不补造分数或心理状态 |
| 控制 | 据反馈调整提示、策略、相对时间投入、必要的外部指导或任务顺序，再观察真实效果 | 保存采取的行动、依据、结果及恢复点；建议与已实施动作分开，失败保留历史 |

三类知识作为调整依据，而不是新增三份档案：

- **关于自我的知识**：用户提供的基础、偏好、优势或困难，以及具体作答暴露的局部薄弱点。单次错误不推断稳定人格或“能力低”。
- **关于任务的知识**：本次目标、重要性、前置依赖、难点、检查范围与完成标准。拆解服务当前问题，不先展开整本书的计划。
- **关于策略的知识**：何时用检索练习、分步示例、图解、重述、交错练习或查阅资料；根据实际反馈保留有效策略，调整无效策略，不预设某种方法对所有人最好。

## 2. 监测信号：主观判断与客观证据分开

| 信号 | 本框架中的含义与时点 | 记录与使用 |
|------|--------------------|------------|
| JOL · 学习判断 | 学习或成功提取后，对之后还能记住、解释或使用多少的预期 | 用户实际表达才记用户自评；与之后同范围的真实表现比较，不直接记为已掌握 |
| FOK · 知晓感判断 | 暂时提取受阻时，对自己是否知道、在提示或再认条件下能否找回的感觉 | “眼熟但说不出”可支持换线索、提示或查阅；单次提取失败不直接判为完全不懂 |
| EOL · 难易度判断 | 对当前子任务学习难度、所需努力的预估；开始前可有，遇阻后可修正 | 自评难度与题目要求、缺失先修、实际错因分开；不是客观能力分，也不是正确率 |
| 完成信心 / 自我效能 | 用户对完成这个具体任务的把握 | 与 JOL、FOK、EOL 分别记录；信心低不等于做错，信心高不等于达标，不从语气或沉默推断 |
| 回溯性监测 | 实施策略后，回看实际表现、卡点和策略效果 | 有真实前后证据才说改善或持续受阻；一条“继续”、消息间隔或助手多讲一遍不是改善证据 |

图中的提取分支保留：**提取成功 → 可选 JOL；提取受阻 → 可选 FOK**。这是监测位置，不要求每次先提问。用户要直接讲解时直接讲；没有发生提取活动就记未观察，不代替用户回答。EOL 与完成信心按需出现，不强求每轮收集四种自评。

## 3. 从监测到控制的闭环

1. **选择当前子任务**：复用目标与断点，确定眼前的完成标准及重要性。例如“能解释为什么此处使用该公式”比“学会第二章”更可检查。仅规划、仅导入、查看和纯导出依旧走各自入口并交付，不启动教学闭环。
2. **激活已有知识**：读取相关历史记录和当前状态；必要且符合用户意图时，以一个回忆、解释或操作任务了解提取情况。主观预期可以用用户已有原话，不先索要量表。
3. **辅导与收集证据**：按需提示、示范、图解或练习。只有学习者真实回答/操作才形成该范围的表现证据；助手示范、生成笔记、阅读材料不代替真实作答。
4. **验证达标与校准预期**：完成标准与个人预测是两回事。有同范围标准和真实作答即可评价本次表现，不要求先提供 JOL 等自评；主观预测与实际证据都存在且条件可比时，再判断高估/低估。缺主观预测仅表示校准证据不足，不抹掉已有作答评价；缺实际证据则保持掌握未评估，不当成低于预期或已经达标。预测未来保持时，需之后的真实检查，当前答对不证明未来记住。单题结论只覆盖单题所检查内容。
5. **选择控制动作**：低于预期时结合具体错因、EOL、用户信心和约束选择下表动作；实际达标但信心低时反馈证据、校准自评，不自动加练。实际达标且无其他需求，可结束当前任务；自评高而证据弱时指出差异并建议针对性检查，不据自信跳过薄弱点。
6. **回溯与再分配**：执行调整，等待真实反馈，再看是否改善；有效则返回同范围检查，无效则换策略、补先修或重新排重要性。用户拒绝测验时尊重选择，可完成本轮讲解，掌握仍为未评估。

| 可见情况 | 控制动作与限制 | 下一观察点 |
|----------|----------------|------------|
| 能提取但解释/迁移仍有差异 | 针对错因做对比、重述或同范围小练习；按需校准 JOL | 下一次真实解释或操作，不扩成整章结论 |
| 暂时想不起，FOK 表示眼熟 | 给一个线索、换表示或查阅相关片段，保留未提示/有提示条件差异 | 能否在相应条件下找回；提示后成功不写成独立提取 |
| 先修缺失或 EOL 显示困难 | 缩小步长、补一个必要先修、用具体示例；相对增加该薄弱点的学习投入 | 实际卡点是否减少，任务要求是否仍相同 |
| 信心低但证据已达标 | 指出具体已做到的部分；可建议以后再检查保持情况 | 信心与证据是否更一致；不强制延长学习 |
| 持续受阻或策略无效 | 回看错因和尝试，换策略或补前置；必要时建议教师/同伴/可靠资料指导，不伪称已联系外部人员 | 新策略的实际结果；是否需要改变目标、预算或范围 |
| 需要重排任务 | 在已约定目标内重新判断重要性，保留原任务题目、证据、断点和暂停原因 | 选中子任务后恢复学习；暂停不标完成 |

**学习时间分配**默认表示相对投入优先级，不输出凭空的分钟数。只有用户给出时长预算或明确请求日程时再分配具体时长；不以聊天时差推算学习时间，不默认生成每日课表或后台排程。

## 4. 人、AI 与等待边界

- **AI 执行**：拆分眼前任务、提供讲解/线索、选择约定范围内的策略、维护笔记和断点。
- **AI 验证**：检查材料引用、真实作答与标准的差异、主观预期和实际证据的可比性、前后策略效果；只根据可见证据反馈，不替学习者作答或编造自评。
- **学习者输入**：实际回答、自评、请求直接解释或跳过检查都是对话输入。待答就停在原题等作答；没有回复不视为成功或同意。不是每次作答都新增一个人工审批门。
- **人工决策门**：改变学习目标、扩大范围、突破用户给定预算、付费或向外部发送资料时，说明已有尝试、待决定取舍及建议恢复点，等待用户选择。一般错题由 AI 调整辅导，不把常规调查推回用户。
- **决策后恢复**：同意继续则恢复当前子任务或策略；同意调整则回到拆解与重要性判断；选择暂停/结束则保存断点后交付。尚未决定保持等待，不默认选中任一方案。
- **回退**：新策略无效且需撤回时恢复最近有效的任务/策略快照，保留尝试与证据日志；换题可恢复原待答题。用户明确删除资料仍按删除契约处理，不为回退另留被删除原文。

“终止学习”在这里区分**当前任务达标**与**用户选择暂停/结束本次会话**，后者不改变掌握结论；没有比较证据也不自动终止或宣称达标。

## 5. 记录契约与旧档兼容

仍使用唯一的 `projects/<教材或主题>/LEARNING_RECORD.md`，不另建记忆数据库或复制学习日志。按 [记录规范](learning-records.md) 在有实际增量时追加：

- **任务与预期**：稳定任务/单元 ID、重要性理由、同范围完成标准、已有的用户预期；完成标准与个人预测分开，建议与用户已确认条件分开。
- **监测**：JOL / FOK / EOL / 完成信心中本轮实际出现的信号、提供者、原话或明确标记的摘要、适用范围与提示条件；未表达就省略或标未提供。
- **证据与校准**：真实题目/操作、实际回答、反馈、相关日志 ID；可比时再写预期差异，不强造百分比。
- **控制与回溯**：选择理由、相对投入或用户给定时间预算、已实施动作/待确认建议、前后证据、策略效果、暂停与恢复点。
- **三类知识的增量**：只记本轮新增且有依据的自我/任务/策略信息，链接已有条件、日志与笔记，不推断长期个人特质。

只保存可见教学状态与简短的决策依据，不保存内部推理。旧记录缺这些字段时继续按原位置恢复，在之后实际教学发生新信号时才补充；查看 `/track` 和纯导出保持只读。

## 6. 再生成与验证

模板仓库根目录：

```bash
python3 manifests/tutor/scripts/render_workflow.py --source manifests/tutor/references/workflow.json --output manifests/tutor/references/workflow.svg
python3 manifests/tutor/scripts/render_workflow.py --source manifests/tutor/references/workflow.json --output manifests/tutor/references/workflow.svg --check
```

安装后的项目根目录（仅 Python 标准库）：

```bash
python3 scripts/render_workflow.py --source references/workflow.json --output references/workflow.svg
python3 scripts/render_workflow.py --source references/workflow.json --output references/workflow.svg --check
```

`--check` 只读；缺图或漂移退出 1，无效图源/节点引用退出 2。安装器分发图、JSON 和渲染脚本。结构与安装测试见仓库 `tools/vibe_tool/tests/test_tutor_metacognition.py`；[会话验收用例](metacognition-cases.md) 是待执行案例，不是已验证教学效果。
