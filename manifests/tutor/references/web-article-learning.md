# 网页文章学习指南

## 特点

网页文章更新频率高、覆盖范围广，但质量参差不齐。需要额外注意来源可靠性验证。

## 学习策略

### 质量评估

使用以下维度评估网页文章质量：
- **来源权威性**: 官方文档 > 知名平台 > 个人博客
- **引用完整性**: 好文章会标注引用来源
- **时效性**: 技术类文章关注发布日期
- **深度**: 覆盖广度 vs 单点深度

### 结构化提取

1. 提取正文，去除导航/广告/页脚
2. 识别文章结构 (H1-H3 层级)
3. 提取关键段落、代码块、数据表格
4. 标注来源 `[Source: URL, 段落标题]`

### 与课程材料配合

网页文章通常适合作为补充材料：
- 官方文档补充 PPT 的理论概述
- 教程文章配合视频课程实践
- 博客文章提供不同视角的理解

### 书签管理

将优质网页文章保存到 `materials/web/`：
- 保存为 HTML 或 Markdown
- 记录原始 URL 和保存日期
- 标注质量评分

当前对话需求优先于本载体的学习方法建议，不固定页数/分钟提问或自动全量提取；只处理选定范围，不强迫先生成路线。
