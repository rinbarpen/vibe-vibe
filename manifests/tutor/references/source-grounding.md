# 源引用规范 (Source Grounding)

## 来源类型先分清

- **教材事实**：只来自实际读过的材料，使用 `[Source: 材料名, 已核验位置]`，包括章名、正文、先修关系和习题号。`STRICT_SOURCE_MODE=true` 约束这些真实引用；即使关闭也不编造出处。
- **通用知识讲解**：没有材料或需要独立解释时可以直接辅导，按段落/笔记标“通用知识讲解”，不宣称来自用户教材，不逐句附 `[unverified]`。有已核验外部来源可引用真实来源；不为常识解释强行索要上传。
- **助手自拟**：例子、练习、干扰项和图示明确标“助手自拟/示意”；依据材料时附真实依据，但不冒充教材原题或原图。
- **真正待核实信息**：OCR 存疑、尚未读到的教材结论、难以确定的事实标 `[unverified]` 并说明具体缺口；需要当前资料的内容按可用工具核验，不以高置信度代替验证。
- **用户信息**：目标、基础、已学范围和自评标“用户提供”，未知待确认；原文与助手摘要在 `LEARNING_RECORD.md` 分区，见 `references/learning-records.md`。保留错误原文，纠错另写。
- **助手安排**：目标、阶段、重点问题、完成标准标 `[规划建议]`；顺序标 `[推荐顺序：沿用目录]` 或 `[推荐顺序：推断]`，不说成作者要求。

用户明确要求只依据所给材料时不混入无标识的通用结论；可说明缺口并请求必要页面。允许材料与通用解释并列，但每段来源边界清楚，不用通用知识补造教材目录。

## 引用格式与定位

格式 `[Source: 材料名, 位置标识]`。以下是格式示例，不是已读过的文件：

| 载体 | 定位示例 |
|------|----------|
| PPT | `[Source: 课件.pptx, P15]` |
| PDF | `[Source: 教材.pdf, PDF页序 18, 印刷页码 5]` |
| PDF 页码未知 | `[Source: 教材.pdf, 第二章 概率基础]`，另标页码待核 |
| EPUB | `[Source: 教材.epub, 第三章, 第2节]` |
| Video/Audio | `[Source: Lecture.mp4, 15:23]` |
| Web | 真实 URL 与已核验小节 |
| Image | 真实图片路径与必要区域说明 |

PDF 页序从 1 开始，和印刷页码分别核验；仅知道一种就只写一种。仅读目录可证明章名/目录标注位置，标“正文待核”，不能证明正文已读或习题已检查。页码未知用已读的章/节；章节也未知就列待补。未核验习题写“习题待核”，核查确实没有才写“未发现教材习题”。

## 多来源与覆盖

每份材料独立路径/索引，同名不等于同一内容；有真实标题/正文/课程说明才对应。PDF 页序与印刷页码、目录证据与正文证据分列；索引保留 partial、已检查范围、未覆盖内容及 OCR 存疑。抽查不能宣称核验整书。本地来源能回到真实原件，网页保留原始 URL 和已保存路径（如有）。

## 笔记与卡片 provenance

知识笔记用 `provenance` 区分 `material`（教材）、`general`（通用知识）或 `mixed`。`source` 只填真实已核验出处：纯通用笔记可为 `[]`，`material` 无教材时省略/为 null，主题单元不伪造章号。自拟例题/图示仍逐项注明；混合笔记中教材段落继续有真实引用。

教材原子笔记和卡片必须有真实 source field/出处；通用笔记/卡片保留 provenance 与自拟说明，不因 `source: []` 标缺教材来源。`MATERIAL_INDEX.md`、`LEARNING_PATH.md`、`LEARNING_RECORD.md` 各用独立模板，不套用原子笔记要求。旧笔记没有 provenance 时按实际内容识别，不批量覆盖用户文件。

## 置信度不是出处

`[confidence: low/medium]` 用于具体不确定性，说明限制；`[unverified]` 只标真正待核实的部分，不等同于“一切无教材的知识”。引用错误时另列更正，不无故删来源或用虚假出处掩盖错误。
