# 学习科学方法论参考

## 1. 主动回忆 (Active Recall)

- **原理**: 从大脑中主动提取信息比被动重读更能强化记忆
- **效果**: 研究表明比重复阅读高效 50%+
- **实施**:
  - 按当前任务和意愿选择闭卷回忆，不固定分钟检查
  - 使用 `/flashcard` 生成 Q&A 卡片
  - 回忆后对比源材料，标记遗漏点

## 2. 间隔重复 (Spaced Repetition)

- **原理**: Ebbinghaus 遗忘曲线 — 信息在刚学习后遗忘最快
- **最优间隔**: 复习安排在学习后 1天 → 3天 → 7天 → 14天 → 30天
- **实施**: 使用 `/review` 和 SM-2 算法自动调度

## 3. 费曼技巧 (Feynman Technique)

- **原理**: 能否用最简单的语言解释 = 是否真正理解
- **步骤**:
  1. 选择一个概念
  2. 用最简单的语言解释（假设听众是门外汉）
  3. 发现解释不清楚的地方 → 回到源材料再学习
  4. 简化和类比

## 4. 交错练习 (Interleaving)

- **原理**: 混合练习不同主题比集中练习效果更好
- **实施**: 复习时混合不同材料、不同主题的卡片

## 5. 具体-抽象交替 (Concrete-Abstract Alternation)

- **原理**: 概念理解需要具体例子和抽象定义交替刺激
- **实施**: 学习抽象概念时强制举例，看到具体案例时抽象出通用原则

## 6. 双重编码 (Dual Coding)

- **原理**: 语言 + 视觉双重编码增强记忆
- **实施**: 笔记中同时包含文字描述和图表/示意图

## 7. 检索练习 (Retrieval Practice)

- **原理**: 测试本身即学习（测试效应）
- **实施**: `/flashcard` 和 `/review` 本质就是检索练习

## 8. 记忆巩固与睡眠

- **原理**: 睡眠是记忆巩固的关键阶段
- **实施**: 睡前复习、醒后回忆
