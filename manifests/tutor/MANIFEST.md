# Project Output Manifest

本文件是本项目唯一的产物登记账本。所有重要任务产出、评审、决策和交付均追加记录于此；`AGENTS.md` 与 `CLAUDE.md` 只链接本文件，不重复维护清单格式或副本。

## 记录规则

- 每项重要产物完成、失败或未执行后追加一行，不覆盖历史记录。
- 时间戳使用 ISO 8601；路径相对于项目根目录。
- Source 记录使用的技能、命令或工作流；Description 说明产物、状态及必要上下文。
- 保留失败/未执行记录并标明状态，不把未完成工作登记为完成。
