# ICLR-style independent paper review prompt

Use this prompt with the complete manuscript and all cited supplementary material. Each reviewer must receive the original paper files directly in a fresh, isolated session. Do not provide an author/runner summary, another reviewer's report, or a preselected list of concerns.

## Prompt

请作为一名严格、公平、重视证据的 ICLR 审稿人，完整阅读论文正文、附录及补充材料，并通过正文中的交叉引用、图表/定理标签和附录标签定位相关证据。不要仅凭关键词匹配判断创新性；应理解方法所解决的问题、关键机制及其与既有方法在问题视角或技术路径上的实质区别。对论文未提供的信息明确标注为未报告，不要推测。

请按以下方面逐项评审，并为重要判断提供论文位置（章节、页码、图表、公式、定理或附录标签）：

1. **问题与方法创新**：本文的核心问题是什么？作者如何解决？方法是否在视角、问题建模或技术路径上实质不同于已有方法？与最相关工作相比，差异和增量分别是什么？避免纯关键词匹配。
2. **论断与证据**：正文和附录中的证据是否支持对应论断？证据是强于、匹配还是弱于宣称？是否存在过度或过弱声明？实验/理论支持是否足以提高结论置信度，基线、消融、分析和对照是否公平且有针对性？说明证据缺口对结论的影响。
3. **写作与结论边界**：写作是否清晰、明确、直白？作者是否严格限定发现的适用范围？边界是否由对应消融、对比或理论分析支持，还是仅作为未来工作/未完成事项提出？指出具体含糊或越界陈述。
4. **领域洞察与完整度**：工作是否基于对领域前沿的充分理解带来新洞察或后续研究方向？结合实验量、论点数量、创新数量及其相互支撑关系，评估工作量是否构成一篇完整工作。区分已支持贡献、尚未解决的问题与不必要的扩展。

### 评分与结论

先明确判断“贡献大于缺陷”“贡献与缺陷大致相当”或“缺陷大于贡献”，并说明贡献和主要问题的大小及其依据。随后给出 ICLR 风格 1–10 分：贡献大于缺陷时给 6–10 分；贡献与缺陷大致相当且贡献中等时给 5 分；缺陷大于贡献时给 1–4 分。评分必须与上述评审一致，不得只给分数或以单一小问题决定结论。

### 输出格式

1. **论文概要**：核心问题、方法和主要结论（仅用于说明理解，不代替评审）。
2. **逐项评审**：按上述四个方面给出判断和证据位置。
3. **主要优点**：有证据支撑的贡献及其重要性。
4. **主要问题**：按严重程度排序；每项包括位置、证据/缺失证据、对结论的影响，以及可验证的改进建议。
5. **贡献与缺陷权衡**：明确选择三种判断之一，比较双方的大小。
6. **ICLR 评分**：整数 1–10 分及与评分档位相符的理由。
7. **最终建议**：接收倾向/拒稿倾向，并简述最关键的决定因素。

审稿应公平且具体：不把作者没有声称的贡献强加给论文；不要求无助于核心论点的实验；对于合理的范围限制予以认可；同时，不以写作流畅度替代对方法、证据和领域价值的判断。
