# Canvas Design Reference

## Overview

Canvas Design is part of the Anthropic skills collection (`skills/anthropics/skills/canvas-design/SKILL.md`). It specializes in posters, design artifacts, and typography-heavy compositions.

## When to Use

- Posters and large-format prints
- Visual design with strong artistic direction
- Typography-heavy compositions
- Brand identity boards
- When you need a design-first (not diagram-first) output

## Typography Considerations

### Font Pairing Principles
- Contrast weight (bold headline + light body)
- Contrast style (serif heading + sans-serif body or reversed)
- Shared proportions (similar x-height, similar character width)
- Limit to 2 font families per design

### Common Pairings
| Heading | Body | Mood |
|---------|------|------|
| Playfair Display | Source Sans Pro | Editorial, elegant |
| Montserrat | Merriweather | Modern, professional |
| Inter | Inter | Clean, tech |
| DM Serif Display | DM Sans | Cohesive, refined |
| Bebas Neue | Roboto | Bold, impactful |

## Color Theory Quick Reference

| Scheme | Structure | Effect |
|--------|-----------|--------|
| Monochromatic | Single hue, varied saturation | Clean, cohesive |
| Analogous | Adjacent hues (3) | Harmonious, natural |
| Complementary | Opposite hues (2) | High contrast, vibrant |
| Triadic | Evenly spaced (3) | Balanced, colorful |
| Split-complementary | Base + 2 adjacent to complement | Vibrant but less tension |
