# AI 视觉创作总入口

用于把一句创作需求组织成可迭代、可交付的图像或视频项目。用户要求直接生成时，检查当前会话可用的生成工具并执行；本技能不假设某个未连接的接口已经可用。

## 先选择场景与模式

| 需求 | 使用场景技能 |
|---|---|
| 单幅画、角色设计、图像编辑、概念图 | `ai-image-workflow` |
| 多格静态漫画、条漫、绘本分格 | `ai-comic-workflow` |
| 剧情驱动的连续镜头、漫剧、动态漫画 | `ai-manhua-workflow` |
| 独立短片、广告片段、文生/图生视频 | `ai-video-workflow` |
| 商品主图、详情图、营销图或商品短视频 | `ai-ecommerce-visual` |

每个场景技能都定义了两种模式：
- **快版**：低成本、小样校准主体/人物身份、关键特征、动作关系与主要背景，不在此阶段追求细节。
- **质量版**：将确认后的设定用于正式生产，处理细节、参考素材、连续性与分项验收，再针对失败项返修。

用户明确要求最终交付、成片、正式素材或高质量时，选择质量版；用户要求试方向、先验证人物/动作、草图或快速预览时，选择快版。模式未明且会明显影响成本或交付期时，先询问模式；否则根据请求措辞判断并说明所选模式。

场景分阶段流程和代表性回归用例见 [`references/workflow-map.md`](references/workflow-map.md)。

## 工具路由

- 图像生成/编辑优先检查当前已接入的 ComfyUI 工作流；复用现成工作流并核验节点、模型、输入与输出能力，不臆造节点/API。
- 文生/图生视频优先检查当前已接入的 Seedance 能力；以当前工具支持的时长、参考输入、比例和输出规格为准。
- 无法调用相关生成工具时，仍完成提示词、分镜、状态文件与可执行的人工步骤；清楚标明未生成的素材，不声称任务已生成。
- 单独安装的场景技能也必须能独立工作；路由名只用来提示用户可继续安装/调用相关场景技能，不假设它们已加载。

## 项目连续性

多图、多格、多镜头或多商品任务时，在用户指定的项目目录中维护 `project-state.json` 和 `continuity.md`；若未指定，先采用当前任务输出目录。JSON 保存机器可续用状态，Markdown 是同一状态的人类预览，不维护两份互相冲突的设定。

JSON 至少包含：`schema_version`、`project_id`、`scenario`、`mode`、`references[]`、`entities[]`、`sequence[]`、`outputs[]`、`qa_issues[]`。实体用稳定 ID；每条参考素材记录类型、路径/标识、用途和作用对象；序列项记录顺序、输入参考、`state_before`、动作、`state_after`、提示词、输出与验收结果。人物/商品的稳定特征与可变化状态分开记录。每次迭代只更新受影响的实体或序列项，并保留此前通过验收的状态。

Markdown 预览按项目、模式、角色/商品卡、参考素材映射、场景/镜头序列、验收与待修问题组织。素材路径使用项目内相对路径，除非用户的上下文要求绝对路径。

模板文件：[`references/project-state-template.json`](references/project-state-template.json)（复制为项目的 `project-state.json`）及 [`references/continuity-template.md`](references/continuity-template.md)（复制为 `continuity.md`）；使用时替换所有示例 ID、状态和路径，保留兼容字段。

## 通用生成闭环

1. 拆解目标、受众/用途、画幅、交付格式和限制；区分稳定设定与本次变化项。
2. 盘点参考图片、参考视频、参考图等输入，为每个素材标注 `identity`、`appearance`、`style`、`composition`、`motion` 或 `scene` 等用途，以及它影响的角色/镜头/商品。不要把参考视频的镜头运动误当作人物身份参考。
3. 快版先做关键样本并据“主体身份、特征、动作/关系、主要背景”确认方向；通过后把批准的设定固化进状态文件。
4. 质量版按场景拆分图像/画格/镜头，传递前序状态和必要参考，生成后逐项验收；失败时只重做相关项，避免无关元素漂移。
5. 保存输出、状态文件、预览表和验收记录；逐一说明已产出与仍待补齐的内容。

提示词说明用中文；交付可复制提示词时同时提供中文版本和英文优化版本，保留同一事实与约束，不引入新设定。

## 稳定性与验收门槛

- 每个序列项记录 `generation`（实际使用的工具/工作流/模型版本、可用的 seed 与参数、运行标识），以及提示词修订号和参考素材 ID；不可获得的字段留空/省略，不能补猜。固定工作流、模型版本、输入素材和 seed 可提高复现性，但不承诺生成模型逐像素相同。
- QA 状态统一为 `draft`、`accepted`、`revise`、`blocked`。按适用项核对身份/商品与参考、动作和对象关系、前后状态、场景构图、细节与交付规格；把结果写入序列项和问题记录。
- **快版通过**：关键主体/人物、稳定特征、动作关系和主要背景均符合需求/参考，才冻结设定进入质量版；任何身份或动作方向错误都返修快版样本，不扩展全量生产。
- **质量版通过**：身份/商品事实、参考约束、关键动作、序列连续性和交付规格等必检项全部通过，且无未关闭的阻断/重大问题；轻微瑕疵可保留，但须记录位置、影响和用户是否接受。若关键事实无法从素材核实，标记待确认而不是判通过。
- 返修只定位到相关实体/画格/镜头/素材 ID，更新状态及提示词版本，再回归检查相邻序列项；保留已通过的基准状态，避免修一处导致其他已验收内容漂移。
