# 美术方向与资产生产契约

## 输入

读取体验支柱、相机、平台与目标设备、现有素材、渲染管线事实和团队产能。尚未选择管线时列候选取舍，不自动改项目或固定某条管线。

## 决策流程

1. 将情绪转为可制作的视觉规则：轮廓、比例、色彩层级、明暗、形状语言、材质和动效节奏。区分玩家/交互物/危险/背景，避免仅用颜色编码玩法信息。
2. 参考板逐项注明来源和借鉴维度；风格参考不等于使用许可。素材台账记录作者、来源、许可、署名、修改/商用限制与核对日期；未知许可明确待核实，采购另行确认。
3. 为实际资产类别建立规格。2D 关注单位像素密度、切片/九宫格、透明边与图集；3D 关注尺度、轴向、枢轴、LOD、UV/材质槽；共同定义命名、碰撞、导入设置和 `.meta` 管理。
4. 预算由代表性设备与场景测量导出：同屏数量、纹理驻留、材质/绘制、透明叠加、骨骼/特效。尚无数据则标“待验证预算假设”，指定垂直切片测量方案，不套用通用面数或贴图大小。
5. 选一个代表性资产验证从源文件→导入→场景→构建的链路，再估算批量产能。说明低规格降级、可复用模块和占位替换规则。

## 输出与验收

交付 `art-direction.md`、资产规格表、素材来源台账与样本验收单；如用户要求生成图片/模型，仅在真实工具产出并检查后登记实际文件，文字描述不登记成已交资产。

验收使用游戏相机、真实尺寸与目标显示比例查看轮廓辨识、交互可读性、导入一致性和预算证据；静态参考板不代替 Unity 场景/设备验证。

`art-director` 将规则交 `technical-artist`、动画特效和 UI 角色，`performance-engineer` 校准预算，producer 核对成本与许可缺口。单个风格任务不自动采购或生成整套游戏资产。

默认输出 `docs/unity-game/` 或指定目录；存在 Unity manifest 时用 `.unity-game/deliverables/`，台账状态建议交主代理汇总。

## 3D专项接力

3D任务可将已确认规格交model-artist，实际使用unity-game-modeling及design/build/surface/rig-export子技能，通过已连接MCP、真实外部软件skill或已安装CLI制作模型。只有实际路径存在才加载；独立使用本技能时仍按本文完成自己的范围，不依赖未安装父包。源模型→导出重开→Unity导入分别验收，technical-artist负责Unity接力，独立reviewer只读复核。
