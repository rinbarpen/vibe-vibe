# 模型设计与生产规格

## 输入与范围

取得资产用途/ID、原画与来源、玩法碰撞、游戏相机、交互距离、目标设备/渲染管线、已存在模型。读取用户指定的修改范围，区分只做概念规格、改现有模型或制作可用 3D 文件。`model-artist` 维护规格，视觉取舍交 `art-director`；未给定目标预算时标假设并安排代表场景实测，不套统一面数。

## 执行

1. 建立前/侧/后视图及关键细节参考，明确比例、尺寸和不可见面的推定；参考图逐项记作者、来源与许可。仅有单张概念图时把背面、结构和材质不确定项列出，不把推测当已确认设计。
2. 用游戏相机距离/投影视角检验大轮廓、视觉层级、交互物识别和模块拼接，先解决剪影再安排微表面细节。真实生成图保存实际文件并检查；没有图像工具可交可执行视图规格，图像制作保持待完成。
3. 明确世界单位、实际尺寸、朝向、pivot/接触面、模块网格和 socket；角色定义站姿/运动范围，静态道具注明不需骨架。碰撞代理按玩法选择简化形状/结构，区分可行走、可拾取与纯装饰。
4. 按资产类别写 LOD/可见距离、三角形/顶点实测口径、材质槽/绘制次数、纹理尺寸/驻留内存、骨骼/影响数预算。指标来自目标设备与同屏场景；未知项列测量责任人和通过条件。
5. 确认源软件及版本、命名/目录、UV/烘焙、材质通道/色彩空间、可选绑定与导出格式。先检查 Unity 实际 importer；glTF/GLB 只在依赖已存在且小样可导入时采用，非默认通用格式。

## 输出与验收

保存 `model-ID-design.md`、真实参考视图（若本任务制作）、许可台账、尺寸/pivot 草图和逐项验收表；包含已定项、未定项、版本与变更理由。每个模型可被 `model-artist` 直接执行，`technical-artist` 可据此验证导入；生产批次前选一项验证源软件→导出→Unity 的小样链路。

有 manifest 时写 `.unity-game/deliverables/` 独占任务目录，否则指定目录，默认 `docs/unity-game/`。本技能不要求已安装父技能。概念规格验收不等于模型制作/导入通过；缺真实文件、工具或运行条件时相关项记 `not_run`。共享阶段状态由 producer 更新；交独立 reviewer 检查设计一致性后再冻结。
