# AI 漫剧

用于剧情连续的动态漫画或 AI 漫剧，从剧本节拍到镜头/片段生成与成片验收。静态漫画分格使用 `ai-comic-workflow`；独立非剧情短视频使用 `ai-video-workflow`。

## 两种模式

- **快版**：用关键镜头/角色样片判断角色是否正确、主要特征、动作是否读得清、人物与道具关系、主要场景是否合适及节奏是否成立。尽量用少量短样校准，不提前精修全部镜头。
- **质量版**：根据批准的角色/场景状态和分镜正式生成各镜头，处理表情、服装褶皱、道具、光线、运动连续性、转场和音画；逐镜检查并只返修有问题的片段。

## 从剧本到镜头

1. 提取集/场/镜头边界、角色出入、对话、动作因果、情绪转折、背景与时间变化；保留用户确认的剧情，不擅自跳过关键行为。
2. 建立角色 Bible：稳定 ID、年龄外观描述（只按用户提供的创作设定）、脸部/发型、服装、体态、声音/表现（如适用）、道具；另列每场的表情、姿势、位置、衣物损伤、持物等瞬态状态。
3. 建立镜头表：顺序、景别、机位/构图、持续时间（若工具支持）、入镜状态、动作、出镜状态、对白/音效、参考素材 ID、衔接点。
4. 快版生成首要角色样片和关键动作镜头；确认身份、动作、背景及参考用途，再进入质量版。
5. 质量版按镜头生成，以前镜头 `state_after` 作为后镜头状态输入；检查剪辑顺序、动作方向、视线、空间位置、道具和声画衔接。

## 参考素材与生成路由

参考图片可锁定身份、外观、服装或美术风格；参考视频可用于运动节奏、镜头运动、姿态变化或转场，须标记具体片段/时间范围和用途，不把其未指定内容复制为新角色设定。记录参考素材影响哪些角色/镜头。

参考图/分镜稿可限定版式与视觉风格；参考视频记录时间范围并标注继承的动作节奏、姿态变化或摄影机运动。对图片/视频/图形参考统一分配素材 ID、用途和影响镜头。

检查当前可用生成工具。图像关键帧/角色参考优先复用 ComfyUI 工作流；视频片段优先检查 Seedance。按当下工具真实支持的参考输入、时长、画幅、音频和导出选项执行；不假定功能或具体参数。若视频生成接入缺失，输出可复用镜头提示词与手工制作序列并标记待生成。

中文镜头模板：`镜头[序号]，承接[前镜头末态]；角色[ID]的固定特征为[特征]，当前[情绪/姿势/持物]；在[场景位置]执行[动作，起点→过程→终点]；镜头[景别/运动]；保持[连续性约束]；参考[素材ID及用途]；画面风格/光线[描述]。`
English: `Shot [number], continuing from [prior end state]. Character [ID], locked traits [traits], current [emotion/pose/held item], performs [action: start → progression → end] at [scene position]. Camera [shot/movement]. Preserve [continuity constraints]. Reference [asset ID and purpose]. [Style/lighting].`

## 连续性状态序列化

在用户指定的创作目录生成 `project-state.json` 与 `continuity.md`。JSON 使用兼容字段：`schema_version`、`project_id`、`scenario`=`manhua`、`mode`=`fast|quality`、`references[]`、`entities[]`、`sequence[]`、`outputs[]`、`qa_issues[]`。`sequence` 按集、场、镜头排序，包含镜头 ID、引用素材、`state_before`、动作、`state_after`、prompt 中英文本、前后镜头关系、输出路径、验收与返修。实体分开记录稳定设定和当前状态。Markdown 展示角色卡、每场状态时间线、镜头衔接和 QA 问题。

仅当状态有依据时更新：角色进出场、动作完成、情绪变化、物品转移等都要写入对应镜头的前后态。不要用静态角色描述替代镜头中的姿态/状态变化。

模板文件：[`references/project-state-template.json`](references/project-state-template.json)（复制为项目的 `project-state.json`）及 [`references/continuity-template.md`](references/continuity-template.md)（复制为 `continuity.md`）；使用时替换所有示例 ID、状态和路径，保留兼容字段。

## 镜头级质量检查

逐镜检查身份/服装/道具、起末姿态、动作因果、背景位置、镜头方向和前后镜衔接；对白文本与说话者、音画同步（如有）、节奏与转场；画面伪影、形体/手脸错误和细节。发现问题时记录镜头 ID、具体断点、应保持事实与局部修复要求。快版主要判断“角色对不对、动作和场景是否成立”；质量版再做细节与连续性总验收。

## 稳定性与验收门槛

- 每个序列项记录 `generation`（实际使用的工具/工作流/模型版本、可用的 seed 与参数、运行标识），以及提示词修订号和参考素材 ID；不可获得的字段留空/省略，不能补猜。固定工作流、模型版本、输入素材和 seed 可提高复现性，但不承诺生成模型逐像素相同。
- QA 状态统一为 `draft`、`accepted`、`revise`、`blocked`。按适用项核对身份/商品与参考、动作和对象关系、前后状态、场景构图、细节与交付规格；把结果写入序列项和问题记录。
- **快版通过**：关键主体/人物、稳定特征、动作关系和主要背景均符合需求/参考，才冻结设定进入质量版；任何身份或动作方向错误都返修快版样本，不扩展全量生产。
- **质量版通过**：身份/商品事实、参考约束、关键动作、序列连续性和交付规格等必检项全部通过，且无未关闭的阻断/重大问题；轻微瑕疵可保留，但须记录位置、影响和用户是否接受。若关键事实无法从素材核实，标记待确认而不是判通过。
- 返修只定位到相关实体/画格/镜头/素材 ID，更新状态及提示词版本，再回归检查相邻序列项；保留已通过的基准状态，避免修一处导致其他已验收内容漂移。
