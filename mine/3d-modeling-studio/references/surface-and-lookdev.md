# UV、烘焙、材质与表现

## UV 与烘焙先于堆材质

- UV 依据变形、可见度、材料和接缝选拆分；checker 检查拉伸/镜像与 texel density，面部/焦点可有明确的分辨率优先级。
- 重叠、镜像、平铺与 UDIM 都是选择，不默认报错；必须记录用途。唯一烘焙区、lightmap 和对称共享的规则不同。
- padding 由输出分辨率、目标 mip 与采样推导：在 4K 图上 16px 的边距，缩到 1K 后只剩 4px。检查实际 mip 远景，避免只在最大分辨率看 UV。
- 高/低模一一对应命名；cage 检查薄片、邻近部件、孔洞与方向。固定最终低模三角化/切线约定，再烘焙并在目标引擎验证。
- Normal、roughness、metallic、height、mask 按数据贴图读取；Base Color 等颜色贴图按色彩管理读取。不要把所有图片一律设 sRGB 或一律设线性。
- OpenGL/DirectX 法线约定按目标设置，必要时正确翻转绿通道并重新验证；不要只凭图像颜色判断。
- displacement 标明位深、midlevel、scale、单位、边界与实际细分方式。16/32-bit 与压缩方式由精度需求决定。

## Substance 3D Painter

- 先确认材质槽/Texture Sets、UV/UDIM 与目标导出预设，烘焙 mesh maps 后检查 log、cage、漏射与串射，不以智能材质能显示为通过。
- 高低模匹配、按名称隔离部件与恰当的投射距离减少相互污染；新版烘焙 UI/自动 cage 功能依安装版本选择。
- 分层顺序建议：基材的颜色/粗糙度/金属与介电属性 → 加工痕迹 → 接触/使用导致的磨损 → 少量微细节。智能遮罩是起点，手工修正不合理的均匀脏边。
- 检查铝/钢/漆面/塑料/橡胶/皮革的粗糙度响应与真实尺度；曲率贴图不直接成为全边缘磨白的理由。
- 保存 `.spp` 与导出 preset、输出通道打包/法线约定；宿主 Python 插件接口先查当前版本，不假设后台渲染服务器或全功能 CLI。

## Substance 3D Designer

- 用参数图表达可复用程序化材质，按从大结构到微结构拆图；暴露物理尺度、颜色变化、粗糙度和形变参数。
- 同一 height 逻辑派生 normal/遮罩/粗糙度时保持因果关系；不要给 Base Color 写死与目标灯光冲突的高光阴影。
- 检查无缝、重复识别、倾斜角、近景和不同贴图分辨率；参数极值不应出现断层/不合理高度。
- `.sbs` 是可编辑源，`.sbsar` 是发布形式，位图贴图用于兼容消费端；SBSAR 支持按目标应用插件和授权核对。

## Marvelous Designer / CLO

- 用裁片、缝合、布纹方向、面料参数与 avatar 碰撞制作真实大褶皱。先确保版型和穿着关系，再增加求解密度。
- 保留服装工程、avatar 尺度与姿势；导出单薄面/厚度、UV 和网格类型与后续绑定/模拟/渲染一致。
- 导出的三角服装能正确模拟不等于已经是目标角色的动画拓扑；重拓扑与细节投射在下游检查。
- UI、脚本/API、批处理能力依据当前产品/版本/许可确定，不把不同产品接口混用。

## Marmoset Toolbag 与渲染器

- Toolbag 可作烘焙和独立 lookdev 检查，按当前版本的 baker、cage、法线/切线设置执行；不预设任意 Python API。
- Cycles / Arnold / V-Ray / Corona / Redshift / RenderMan 按实际宿主、版本、硬件与授权选择，先测试小图和关键材质再跑最终图。
- 中性灰/材质球与标准灯光验证基础；表现灯光另存。使用长软箱检查曲面，以侧/逆光检查厚度与透射。
- beauty、灰模、线框、关键近景各司其职。beauty 可以优化构图，但检查图应看清完整资产、背面和底部，不用景深/雾/黑位遮挡缺陷。
- 检查噪点、萤火虫、去噪抹细节、色彩管理和输出位深。没有跨 DCC 一致的配置时，不宣称自动做到完全一致的色彩。

## Unreal / Unity / Web 交付

- 再导入核对单位、坐标轴、三角化、切线、材质、透明、骨骼和依赖；glTF、FBX、USD、Alembic 各有信息边界，选择前明确消费端。
- Unreal Nanite 的平台、变形/材质能力随版本演进；查实际版本官方支持，不引用旧版限制当永久事实，也不把 Nanite 当作无限面数许可。
- Unity 或 Web 以实际渲染管线、硬件和帧预算测量；纹理流送、压缩、LOD、蒙皮、透明 overdraw、draw calls 都可能先于面数成为瓶颈。
- 引擎内证据至少含规定机位、场景负载、帧时间和内存测量方法；单个资产空场景的 FPS 不代表项目预算。
