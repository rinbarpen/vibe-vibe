# 技术与视觉质量门禁

## 先定义“优秀”的可观察含义

“业内优秀”不是一个固定面数门槛。先选择可查看的同类标杆、用途与镜头，再分别判断：

- 轮廓与比例准确、视角改变仍成立。
- 结构、装配、解剖或受力可信。
- 主次微形层次清楚，局部精细但整体不嘈杂。
- 曲面、布线、变形、UV 与材质适合实际用途。
- 模型可编辑、依赖完整、交换件确实能重新打开。

下面的数值为**本 Skill 的建议验收起点，不是行业统一标准**；按 brief 修改，保留修改理由。

## 高模密度与预算

- 估算全四边面细分：`F(level n) ≈ F0 × 4^n`。4 万四边面加 3 级约 256 万面，4 级约 1024 万面；最终评估还应计算其他修改器、实例、毛发和置换。
- 不限定所有作品必须百万面；近景大角色可能需多百万面雕刻，小型产品控制笼可能很少但渲染细分足够，CAD 原档用曲面精度而非面数衡量。
- 曲率采样可从圆弧弦误差估算：半径 `r`、容许误差 `e` 时，单段角度上限约 `2 arccos(1-e/r)`，单位一致、`0 < e < r`。按可见轮廓误差选择分段，最后用实际镜头检查。
- 可把重要轮廓的变化控制在最终图约 0.5–1px 内作为初始目标；这只是镜头相关的经验起点，不适用于制造公差或所有风格。
- 几何内存不只看顶点/面索引；还含修改器中间态、UV、属性、BVH、纹理、实例实现与渲染副本。先测代表性部件、记录峰值和耗时，再扩展。

## 阶段门禁与回退

| 阶段 | 证据 | 通过条件 | 失败回退 |
|---|---|---|---|
| 大形 | 六正交、两三分之四、参考对照 | 身份/比例/轮廓与 brief 一致；遮挡区假设明确 | 回低级体块/截面 |
| 结构 | 灰模、剖面/连接近景、线框 | 厚度/连接/解剖可信，无明显穿插/飘浮 | 修部件关系/局部拓扑 |
| 精修 | 最终尺寸近景、曲面扫光、细节分区 | 曲面稳定、细节有依据、焦点清晰 | 减噪/重整次形，不继续加细分 |
| 技术 | 几何/UV/依赖/用途专项报告 | 检测范围内无阻断项，未覆盖项另有证据 | 回问题对象；必要时重做派生 |
| 材质 | 中性灯光 + 目标灯光/引擎 | 尺度、色彩、粗糙度、法线/透射合理 | 修材质/UV/烘焙 |
| 交付 | 新场景打开/再导入日志与清单 | 单位、轴、层级、材质和依赖符合约定 | 回导出设置/资源收集 |

## 分用途技术检查

### 全部多边形资产

- NaN/Inf 坐标、空网格、零面积面、面上未使用的孤立结构应有修复或明确理由。
- 法线朝向、叠面、z-fighting、意外穿插、变换与单位正确；合理的 open shell、眼球/服装等独立交叠不一律报错。
- 全四边面不是普适要求：变形/细分关键区看边流；静态平面 n-gon/三角在消费端稳定时可用；最终三角数单独统计。
- UV 是否存在与 UV 是否合格是两回事。检查缝、拉伸、密度、重叠意图、padding、UDIM 和贴图关联。
- 缺贴图、缓存、外部链接、字体或插件要在交付前处理；审计覆盖不到的依赖人工检查。

### 动画与角色

- 列出目标动作/表情/镜头，逐一检查极值，包含肩髋、肘膝、口眼与手指；记录挤压、体积、折痕和穿模。
- 自动重拓扑输出即便全四边面也不自动通过。用实际绑定/形态测试检查；静态布线截图只作补充。

### 实时

- 遵守项目明确的 tris、材质槽、贴图/内存、帧时间预算；LOD 切换、碰撞、蒙皮和透明视角实际测试。
- 烘焙的三角化与切线基准匹配目标引擎。Nanite 等新能力按实际版本/平台核实，不写永久过时的限制。

### 打印、工业

- 打印：闭合/流形只是起点，还检查自交、局部厚度、最小特征/孔、装配间隙、排液、支撑和切片；阈值来源于工艺/设备。
- CAD：原生实体有效性、尺寸/单位、曲面连续性、装配与公差专项检查；网格“无破面”不是 CAD 工程验收。

## 多视角要求

默认前 `-Y`、后 `+Y`、左 `-X`、右 `+X`、顶 `+Z`、底 `-Z`；如果工程有其他约定，先对齐说明。

建议最少：六正交灰模、两个三分之四、至少两个问题/焦点近景和一张真实拓扑线框。有背面结构或动画要求时补相应视图；用户只要草模时按任务缩减并标明阶段。

`blender_review.py` 能生成六正交与两三分之四辅助图；不包含转台动画、自动线框、定制近景和光照完整匹配。检查 Geometry Nodes 实例、曲线/毛发和变形时按执行指南先确认支持范围。

## 建议艺术评分

按各项 0–5 评分，再以 `score/5 × weight` 加权；0=缺失，1=明显错误，2=大幅落后，3=可信可用但仍有显著差距，4=接近选定标杆，5=在本次参考/用途下充分达到目标。没有实际查看证据的项保持待评，不补猜分。

| 项 | 权重 | 主要证据 |
|---|---:|---|
| 轮廓与比例 | 20 | 正侧背、剪影、同机位参考 |
| 结构可信度 | 15 | 装配/解剖/受力、厚度与局部 |
| 拓扑与表面连续 | 15 | 线框、扫光、用途专项测试 |
| 次形与微细节 | 15 | 最终分辨率近景、细节分区 |
| 材质与 UV | 15 | 中性光、checker、贴图/烘焙 |
| 表现与多面完整性 | 10 | 多视角、背底面、焦点和构图 |
| 可编辑性与交付 | 10 | 原生文件、依赖、重新导入 |

建议“高质量”门槛：总分 ≥90，所有适用项 ≥3，且**零未关闭 critical/major 问题**。不适用项写明原因并按剩余权重重新归一化；评分是评审辅助，不是“达到行业水平”的客观认证。

`visual_review.status=accepted` 必须由实际查看后的评审填写，并链接评审记录；自动几何或交付脚本保持这个字段原值，不代替视觉判断。

## 返修记录最小字段

`id / object / view / reference / severity / observation / fix / regression_evidence / status`。

- `critical`：工程打不开、关键结构缺失、用途阻断、资产损坏。
- `major`：比例、结构、明显穿插、曲面破坏、目标镜头严重缺陷或显著超预算。
- `minor`：不阻断用途的小瑕疵；记录位置及是否接受。

先修高影响项，不每轮全资产重建。关闭问题需实际回归证据；若仍有重大缺陷，应交付阶段成果与明确待办，不使用“最终通过”。

## 自动审计范围

`blender_audit.py` 报告当前 view layer 下、所选集合的**原始 Mesh 对象**与**viewport evaluated mesh**：顶点/面/三角、包围盒、有限值、边界/多面共边、孤立结构、退化面、UV 层存在与图片依赖。支持 `--closed-solid` 把开口/非流形升级为错误，`--require-uv` 要求 UV 层。

它不检测自相交、局部壁厚、重叠 UV、形变质量、倒角美感、CAD 连续性或所有外部依赖；不把 viewport 与 render subdivision 混为一谈。实例/非 Mesh、复杂 Geometry Nodes、最终渲染密度另行验证。
