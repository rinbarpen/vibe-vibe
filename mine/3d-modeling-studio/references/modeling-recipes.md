# 精细建模配方：效果 → 结构 → 技术 → 验收

## 目录

- 硬表面/产品
- 写实角色与生物
- 二次元/风格化角色
- 布料、服装、毛发
- 建筑、环境、植被
- 珠宝、浮雕与打印
- 扫描或生成网格清理
- 细节预算与针对性返修

这些配方是选择依据，细节和数值须落到具体模型、尺度与镜头。

## 硬表面/产品：干净曲面、可信装配、精密高光

**适合**：Blender / Maya / Max / C4D；需工程精度时 Rhino / Fusion / SolidWorks / FreeCAD。

1. 分壳体、结构件、连接件、软材质与内部件；建立接缝、厚度和可拆装关系。先验证主体截面与开口，而非先做螺丝。
2. 曲面主体用少而有效的控制笼/截面，布尔在大形稳定后加入。高曲率处控制边流，平坦处不均匀堆细分。
3. 主轮廓倒角、功能边倒角、微倒角分层；圆角半径按加工/注塑/风格依据确定。接缝不是漆黑细线，应有宽度、深度、阴影或材料变化。
4. 微结构分别选：改变轮廓的滚花/齿/通风口用几何或实例；近景有视差的浮雕用置换；微划痕/喷砂主要由粗糙度与法线表达。
5. 细节克制：紧固件遵守受力与装配逻辑，磨损在接触和使用区域；不把所有边统一磨白。
6. 用长条光源扫曲面，检查反射波纹、夹痕、黑斑、贴面闪烁、倒角相交；看后盖、底部与接口。修复局部曲率后再恢复材质。

**交付加项**：装配层级、关键尺寸、可编辑 cutter/参数，至少一张局部线框和一个曲面扫光视角。机械精度需求另交实体/尺寸检查。

## 写实角色与生物：解剖、重心、层次化雕刻

**适合**：ZBrush / Blender 雕刻，Maya / Blender 重拓扑，Substance 等做表面。

1. 建参考板：体型、骨点、头身比例、表情、皮肤/鳞甲、年龄感或物种特征。先看剪影和骨架比例，再看肌肉。
2. 低层级雕头颅、胸廓、骨盆和四肢节奏，正侧/三分之四交叉看体积；保持自然重心和关节方向。
3. 次形解释脂肪、肌肉、骨点与软组织厚度，左右差异有依据；皮褶顺拉伸/挤压与附着关系，不任意刻线。
4. 面部依次看颅骨、眼眶、颧弓、上下颌、唇鼻耳。眼球、眼睑厚度、泪阜、牙龈/口腔按镜头需求建；不要只有前面一张漂亮面具。
5. 细分后逐级补褶皱、皮肤分区、毛孔和微毛；回低层修体块，高层细节不替代比例。
6. 动画派生网格：眼口环、鼻唇沟、肩髋、肘膝与手指边流经实际动作检查。保留高模投射源，重拓扑后逐级投射，防止眼睑/指缝串面。

**交付加项**：正侧背灰模、头/手/关节近景、雕刻层级说明；有绑定要求时附规定动作或表情极值检查。静态雕塑和动画资产分别验收。

## 二次元/风格化：设计控制比表面噪声重要

**适合**：Blender / Maya / ZBrush；以目标游戏/动画渲染器验证最终观感。

1. 先定义造型语言：头身、眼形、鼻口简化、手脚尺寸、面部侧面、发块节奏、轮廓线与色块。风格化不是省略结构检查。
2. 脸部同时看正面、侧面和三分之四；检查眼窝凹陷、嘴鼻突出和脸颊转折。不要为了正面立绘让侧脸塌陷。
3. 头发先分大束与流向，再做次束、转折、遮挡和少量碎发；发根连接、发片厚度、背面和穿插都检查。
4. 服装保留厚度、领口/袖口结构与有选择的褶皱；装饰围绕视觉焦点，避免平均铺满。
5. Toon/风格化着色时，面部法线编辑与阴影遮罩是独立表面设计；不把它们误当真实几何修复。验证转头、移动灯光、眨眼与张嘴，检查阴影跳变。
6. 清楚区分原生网格、描边壳、发片、透明片和材质遮罩；引擎中看背面剔除、透明排序、描边距离变化及目标分辨率。

**效果标准**：剪影识别、面部多角度稳定、发束节奏清楚、色块有主次；无需额外毛孔或写实磨损来“增加精细度”。

## 布料、服装与毛发

- Marvelous Designer / CLO 类工具：以版型、布纹方向、缝线、层间碰撞和面料参数建立服装；试穿和大褶皱稳定后降低粒子距离/提高求解精度。
- 粒子距离与项目单位、服装大小相关；数值减半通常显著增加计算负担，先测局部，不把固定毫米数当所有服装的标准。
- 先有重力/拉力导致的大褶与张力点，再做压褶、细褶和缝线；腋下、腰带、袖口、接触区域逻辑一致。
- 导出前区分单层/厚壳、焊接/独立裁片、UV 与三角/四边面选项；动态动画保留可模拟拓扑，静态可另做精修派生。
- 眼睫/发片/毛发卡片按轮廓和束群分级；真实 groom 先导向再加密度和 flyaways。近景检验发根、交叉、穿模和高光，不用密度遮盖导向错误。
- 缝线、拉链、扣件用实例/曲线；纹理织纹按真实尺度，远景注意摩尔纹与过度凹凸。

## 建筑、环境、植被

- 先确定人尺度、模块尺寸、网格对齐、构图和可探索范围；只被一张主图遮住的背面不是完整环境。
- 环境按 hero / secondary / background 分密度。重复结构用模块、实例、trim sheet/平铺材质；接缝、转角与材质尺度统一。
- 建筑先保证承重/连接的视觉可信度、门窗尺寸、墙体厚度和地面接触；破损按材料断裂与受力组织，不随机炸碎。
- 岩石先定块面、层理、风化方向；扫描岩石保轮廓、清底部和材质。植被按主干→枝级→叶簇→局部叶片，验证轮廓、透光、背面与风动。
- Houdini/Geometry Nodes 参数化时测试尺寸、密度、非对称与种子极值。实例、碰撞、LOD、透明 overdraw 和流送分别检查。
- 需要可玩场景时，目标引擎里实测 draw calls、显存、GPU/CPU 时间、碰撞与光照；高模渲染成功不等于实时预算达标。

## 珠宝、浮雕与打印

- 珠宝先定戒围、宝石尺寸、镶口、爪厚与连接，再做花丝/刻纹。视觉模型与实际镶嵌工艺版本分开。
- 曲线扫掠/参数阵列表达花丝，雕刻表达有机浮雕；保持底板、最小结构和连接处的真实厚度。
- 打印派生确认单位、闭合流形、朝外法线、自相交、孤岛、最小壁厚/特征、间隙、排液与支撑；阈值由工艺/材料/设备决定。
- `blender_audit.py --closed-solid` 只筛查部分网格结构，**不是可打印认证**；使用厚度/相交检查与实际切片预览补证据。
- 制造版本附真实尺寸和工艺约束；单张金属材质渲染不证明花丝可生产。

## 扫描或生成网格清理

1. 留存原始网格、贴图、来源和单位；识别前后比例、部件融合、浮片、洞、残余背景与纹理烘光。
2. 先修主形/结构和背面，再清拓扑、孔洞、法线。需要动画时手动重建关键边流；需要机械精度时重建曲面/实体。
3. 贴图投射到新网格，检查 UV 接缝、阴影烘死、色差与重复纹理；法线图不修复轮廓凹陷。
4. 对照可见参考，明确未观察区域的重建假设；保留能返工的高模，不把一次自动减面当完整优化。

## 细节预算与针对性返修

| 观察问题 | 优先处理 | 避免的误修 |
|---|---|---|
| 正面相似、侧面塌陷 | 低级体块/截面与正侧对照 | 增加毛孔或贴图锐度 |
| 曲面高光起皱 | 控制笼、极点、曲率与法线来源 | 单纯提高细分等级 |
| 机械件像塑料玩具 | 倒角层级、厚度、装配与材质尺度 | 全场提高金属度 |
| 雕刻“脏”、细节发糊 | 降噪，恢复主次形，分区重建细节 | 一轮全表面 alpha |
| 侧背面简单、缺结构 | 补真实连接、厚度、后盖/背部设计 | 只换主图机位 |
| 游戏资产烘焙黑边 | cage、硬边/UV、命名匹配、三角化/切线基准 | 在 Base Color 涂黑掩盖 |
| 模型精细但观感平 | 明暗组织、粗糙度、材质差异和焦点 | 一味增加面数 |

每轮返修只选影响最大的 1–3 项，记录对象和机位；保留基准后比较实际变化，技术检查和视觉评审都通过再收尾。
