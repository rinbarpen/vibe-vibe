# AI 漫画

用于静态多格漫画/条漫/绘本，不负责将剧情制作成动态漫剧；有连续视频镜头时使用 `ai-manhua-workflow`。

## 快版与质量版

- **快版**：只做剧情节拍和关键画格样本，快速确认人物身份、外观特征、动作关系、主要背景和阅读方向。以小样/低细节预览校准为主，不逐格打磨纹理和装饰。
- **质量版**：锁定角色卡、画风、页面网格与已确认分镜；按页和画格正式生成，核对阅读顺序、表情动作、气泡/文字、场景轴线、光线与背景连续性，定位返修单格。

若用户想先确认角色或剧情走向，先快版；明确要求成稿/出版/交付时走质量版。

## 生产流程

1. 整理故事梗概、读者、页数/格数、阅读方向、画幅、对白和文字语言。剧情缺口仅补足维持分镜所需的信息。
2. 建立角色卡：稳定身份、脸型/发型、体态、服装关键件、常用道具、基准色和不可漂移特征。将情绪、姿态、伤痕/污渍、持物等作为可变状态并标注出现画格。
3. 写逐格脚本：格号、景别/角度、角色与位置、动作、表情、背景、对白、前置状态、结果状态、所需参考素材。
4. 用快版验证一页/关键格；通过后固化风格及角色参考，再进入质量版逐格生产。
5. 依阅读顺序检查页面和跨页连续性；修复时以格号为单位记录，不重做已通过且未受影响的格子。

## 参考与提示词

把参考图片映射到角色身份、外观/服装、画风、构图或场景；参考图不可默默覆盖用户文字设定。同时接收参考视频（提取指定时间点的动作/姿态或镜头构图）和参考图/版式稿（页格布局、视觉风格）；记录时间点、用途与受影响画格，不能让参考覆盖已确认角色设定。

每格提示需携带当前角色 ID 与必要的 `state_before`，并描述镜头、动作、背景、表情、对白/排版约束。

中文模板：`角色[ID]（固定特征…，当前状态…）在[场景/位置]，以[景别/视角]表现[动作及对象关系]；延续上一格[连续性事实]；[表情/光线/风格]；对白准确为“[文本]”；保持[不可改变项]。` 
English: `Character [ID] ([locked traits], current state) in [setting/position], [shot/angle] showing [action and interaction]; continue [continuity facts] from the prior panel; [expression/lighting/style]; exact dialogue: “[text]”; preserve [invariants].`

## 项目状态文件

在输出目录维护 `project-state.json` 与人工可读的 `continuity.md`。共享 JSON 字段：`schema_version`、`project_id`、`scenario`=`comic`、`mode`=`fast|quality`、`references[]`、`entities[]`、`sequence[]`、`outputs[]`、`qa_issues[]`。`entities` 为稳定角色 ID 与稳定/可变特征；`sequence` 逐格有序，包含 `sequence_id`、`order`、引用 ID、`state_before`、`action`、`state_after`、prompt 中英文本、输出路径、验收状态和返修项。Markdown 按角色卡、参考图用途、页/格顺序和问题清单呈现同一状态。

角色状态变化必须显式反映在后续画格；不得把“上一格已拿在手里的道具”在下一格丢失，也不得无缘由恢复受损服饰、位置或情绪。

模板文件：[`references/project-state-template.json`](references/project-state-template.json)（复制为项目的 `project-state.json`）及 [`references/continuity-template.md`](references/continuity-template.md)（复制为 `continuity.md`）；使用时替换所有示例 ID、状态和路径，保留兼容字段。

## 逐格 QA

- 所有格人物身份、稳定外观、服装、道具与批准参考一致。
- 前一格结束状态与当前格开始状态衔接；动作有方向、起因和结果，物体交互可信。
- 背景位置、时间、轴线、视线及光照跨格合理；情绪/伤痕/持物变化有剧情依据。
- 阅读顺序明确；对白归属、文字内容、气泡顺序和安全边距正确。
- 快版只判定人物、动作/关系、背景和阅读节奏；质量版再核查线条、手脸、细节、文字与最终尺寸。

## 稳定性与验收门槛

- 每个序列项记录 `generation`（实际使用的工具/工作流/模型版本、可用的 seed 与参数、运行标识），以及提示词修订号和参考素材 ID；不可获得的字段留空/省略，不能补猜。固定工作流、模型版本、输入素材和 seed 可提高复现性，但不承诺生成模型逐像素相同。
- QA 状态统一为 `draft`、`accepted`、`revise`、`blocked`。按适用项核对身份/商品与参考、动作和对象关系、前后状态、场景构图、细节与交付规格；把结果写入序列项和问题记录。
- **快版通过**：关键主体/人物、稳定特征、动作关系和主要背景均符合需求/参考，才冻结设定进入质量版；任何身份或动作方向错误都返修快版样本，不扩展全量生产。
- **质量版通过**：身份/商品事实、参考约束、关键动作、序列连续性和交付规格等必检项全部通过，且无未关闭的阻断/重大问题；轻微瑕疵可保留，但须记录位置、影响和用户是否接受。若关键事实无法从素材核实，标记待确认而不是判通过。
- 返修只定位到相关实体/画格/镜头/素材 ID，更新状态及提示词版本，再回归检查相邻序列项；保留已通过的基准状态，避免修一处导致其他已验收内容漂移。
