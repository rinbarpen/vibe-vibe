# Awesome Design MD

A curated collection of DESIGN.md files from 74 major brand design systems. Use this as a reference when designing user interfaces, component libraries, or visual design systems.

## Location

All design system references are in `skills/awesome-design-md/design-md/`.

## How to Use

1. When asked to design UI matching a specific brand, first check `skills/awesome-design-md/design-md/<brand>/DESIGN.md` for that brand's design system.
2. Each brand folder contains:
   - **`DESIGN.md`** — Full design system documentation (colors, typography, components, layout, elevation, do's/don'ts, responsive behavior)
   - **`preview.html`** — Light mode visual catalog of color swatches, type scales, buttons, and cards
   - **`preview-dark.html`** — Same catalog on dark surfaces
3. Apply the design tokens from DESIGN.md when generating UI:
   - Color palette (primary, neutral, accent, semantic colors)
   - Typography (font families, scale, weights)
   - Component specs (buttons, inputs, cards, navigation)
   - Layout and spacing system
   - Elevation and depth patterns
4. If no specific brand is requested, browse the collection for general design inspiration.
